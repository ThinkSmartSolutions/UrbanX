## 1. Date generale și tema de proiectare

Memoriu de arhitectură DTAC pentru **HOTEL 4 stele, S+P+6E, ~100 camere** (cazare + restaurant + SPA/piscină + săli conferință + subsol parcare).

| Element | Valoare |
|---|---|
| Ac / Acd | ~1.150 / ~8.900 mp (cu subsol) |
| Capacitate | ~100 camere (198 locuri) |
| H atic | ~24,50 m |
| Categoria importanță | **B — deosebită** (HG 766/1997) |
| Clasa seismică | **II, γI,e 1,2** |
| Grad RF | II |

**Justificare B (nu C):** cazare colectivă >100 locuri cu aglomerări de persoane → clasa II seismică + verificare A1.

**Cadru normativ:** Legea 50/1991, 10/1995, **Ordin ANT 65/2013**, P118-1/2/3, OMS 119/2014, NP 051/2012, C107, **C125/2013** (acustică — critic), Legea 372/2005, GP 063-2001 (bucătării), NP 068-2002 (săli aglomerate), STAS 6472/C107-6 (condens piscină), P100-1/2013, NP 057/2002, HG 907/2016.

**Temă 4★:** ~100 camere (mix standard/superior/suite/apartament), restaurant clasificat + bar + bucătărie profesională, săli conferință modulare (~300 locuri) + foaier, SPA (piscină interioară, saune, fitness, tratament), parcare subsol.

## 2. Tipuri de cazare + hotel 4★

Ordin ANT 65/2013: hoteluri, apart-hotel, moteluri, hosteluri, vile, pensiuni. **Tratat: hotel 4★.** Cerințe-cheie 4★: cameră dublă ≥15 mp (proiect 17-18), single ≥11, apartament 30-35 + baie, GS cameră ≥4 mp (proiect 4,5-5,0), H liber ≥2,60 (2,70), recepție 24/24, ascensor obligatoriu >P+1, climatizare toate spațiile, restaurant clasificat, room-service ≥16h, GS 100% camere, camere PMR (1/50), insonorizare uși/ferestre.

## 3. Amplasament, orientare, urbanism

Acces din drum cat. II, separarea circulațiilor (oaspeți față + porte-cochère / personal-marfă lateral-spate / auto subsol rampă ≤15% ≥3,50 m/sens).

| Spațiu | Orientare | Justificare |
|---|---|---|
| Camere | E/SE/SV | însorire matinală, evitare supraîncălzire V |
| Restaurant + terasă | S/SV | soare după-amiază, vedere |
| Săli conferință | N/interior | control lumină proiecție |
| Bucătărie/spălătorie | N/spate | evitare supraîncălzire, aproape marfă |
| SPA/piscină | curte/grădină | intimitate + lumină difuză |

Camere pe fațadele cu vedere; fațada nefavorabilă (N/calcan) → circulații, oficii, tehnice.

## 4. Program funcțional și zonare (FOH/camere/BOH)

**Front-of-house** (public), **camere** (etaje curente), **back-of-house** (serviciu). Regula: fluxul oaspete și fluxul serviciu nu se intersectează (decât controlat — oficiu etaj, room-service prin lift serviciu).

| Nivel | Funcțiuni |
|---|---|
| Subsol | parcare ~45, CT/hidrofor/tablouri/TGD, rezervor incendiu + pompe, spălătorie, depozite, vestiare |
| Parter | lobby dublă înălțime, recepție, lounge/bar, restaurant + terasă, bucătărie, săli conferință + foaier, SPA/piscină/fitness |
| E1 | camere (parțial conferință mari) |
| E2-6 | camere (etaje curente) |
| Terasă | HVAC, chillere, panouri, luminatoare |

**Suprafețe (mp util):** FOH 1.910 (lobby 320, lounge 140, restaurant 260 + terasă 120, conferință 460, SPA 520, GS 90); camere 3.980 (camere+băi 3.200, circulații/oficii 780); BOH 2.400 (bucătărie 240, spălătorie 110, depozite 130, birouri 120, vestiare 90, tehnice 260) + parcare 1.350. **Total util ~8.290.**

## 6. Izolarea fonică (C125/2013) — criteriu critic

| Element | Indice | Cerință | Țintă 4★ |
|---|---|---|---|
| Perete între camere | R'w | ≥50 | **≥52 dB** |
| Perete cameră-coridor | R'w | ≥40 | ≥45 (ușă ≥32) |
| Planșeu camere (aerian) | R'w | ≥51 | **≥53** |
| Planșeu (impact) | L'n,w | ≤58 | **≤53** |
| Perete cameră-lift/CT | R'w | ≥55 | **≥58** + decuplare |
| Fereastră (trafic) | R'w | ≥30-33 | **≥35** (geam asimetric) |

**Soluții:** perete dublu GK pe structură decuplată (2×12,5/față + vată 2×50) sau zidărie 25 cm; **planșeu cu șapă flotantă** pe strat elastic (cheia pt. L'n,w ≤53); uși fonoizolante + prag automat; instalații decuplate (manșoane elastice, coliere, pompe pe ploturi); camere ferite de lift/CT/tobogan/gunoi (spații-tampon interpuse).

## 7. Circulații: lobby, coridoare, scări, ascensoare

**Lobby dublă înălțime** (~7 m, recepție 2 posturi + concierge). **Coridoare** ≥1,50 (1,80), mochetă fonoabsorbantă, iluminat siguranță. **Scări:** min. 2 case evacuare (nucleu + capăt), rampe ≥1,20, ventilate/desfumate (P118).

**Ascensoare** (1 la 60-90 camere + serviciu):

| Ascensor | Nr. | Capacitate | Destinație |
|---|---|---|---|
| Oaspeți | 2 | 13 pers/1.000 kg | S-6E; unul PMR/targă (≥1,10×1,40) |
| Serviciu/bagaje | 1 | 1.600 kg | camerista, room-service, marfă |

2 oaspeți + 1 serviciu → așteptare <40 s la vârf + separare fluxuri.

## 8. Accesibilitate PMR (NP 051/2012)

Min. **2 camere adaptate** (1/50, la etaje joase lângă lift+scară); traseu continuu (parcare PMR 3,50 min. 2 → lift → recepție → restaurant → SPA → cameră), prag ≤2 cm, rampe ≤8% (5%); **baie PMR ≥6,5 mp** (Ø1,50, bare rabatabile, WC 46-48, lavoar accesibil, duș fără prag + scaun); uși ≥0,90; ascensor ≥1,10×1,40 + Braille; recepție blat coborât 0,80 + buclă inductivă + alarmă vizuală+sonoră.

## 9. Restaurant + bucătărie (flux GP 063 / OMS 119)

Restaurant ~260 mp, 130-150 locuri (1,6-1,8 mp/loc) + terasă 120. **Bucătărie „marche en avant":** recepție marfă → depozitare (uscate + frig +2/+4°C + −18°C separate) → preparare primară (legume/carne/pește separate) → gătit (hotă cu extracție + aport + stingere automată) → distribuție (pass, sens unic) → debarasare → spălare → deșeuri (cameră refrigerată, traseu separat) + vestiar-filtru personal. Finisaje: pereți lavabili, faianță ≥2,10, pardoseală antiderapantă cu sifoane + pantă, tavan lavabil, separator grăsimi.

## 10. SPA / piscină / wellness

Piscină interioară ~12×6 (~72 mp luciu), saune (uscată/umedă), relaxare, 4-6 cabine tratament, fitness, vestiare/dușuri pe sexe. **Cerințe tehnice:** aer 28-30°C, UR ≤65%, apă 28°C; **risc condens → verificare punct de rouă (C107-6) + barieră vapori continuă + dezumidificare mecanică dedicată**; tratare apă (recirculare + filtrare + clor/UV + bazin compensare); finisaje ceramice antiderapante R11 + hidroizolație + rezistente clor; **ventilare independentă**, presiune ușor negativă vs. spații alăturate.

## 11. Securitate la incendiu (arhitectură, P118)

**Oaspeți care DORM** → detecție + evacuare sporite. Grad RF II; camere = compartimente cu uși **EI 30 autoînchidere**; case scări **EI presurizate/desfumate**; puțuri lift ghene EI. **Evacuare:** min. 2 căi distincte/etaj (nucleu + scară capăt, două direcții din orice cameră); uși spre exterior; iluminat siguranță + indicatoare + plan evacuare pe interiorul ușii camerei. **Detecție automată în FIECARE cameră** + coridoare/tehnice/bucătărie; centrală 24/24 la recepție; **alarmare vocală** + sirene + optic (PMR/hipoacuzici); hidranți int./ext. + sprinklere unde impune normativul.

Termosistem vată bazaltică A1 (reacție foc), fără punți; tâmplărie tripan low-E (geam asimetric fonoizolant la fațada expusă); verificare condens piscină (C107-6); nZEB (pompe căldură, solar ACM, recuperare ventilație).

## 14. Concluzii

Hotel S+P+6E 4★ ~100 camere răspunde criteriilor ANT 65/2013 (suprafețe+dotări+restaurant+ascensoare+climatizare+insonorizare). Categoria B + clasa II (γI 1,2) justificate de cazarea colectivă cu aglomerare. **Confort acustic C125 prioritar** (R'w ≥52 camere, L'n,w ≤53 șapă flotantă, uși + prag automat, instalații decuplate). Securitate incendiu „oaspeți care dorm" (detecție în fiecare cameră, 2 căi/etaj, EI, alarmare vocală). PMR (2 camere adaptate + traseu). Bucătărie „marche en avant" + SPA cu soluții higrotermice. Anvelopă C107/nZEB, POT 35,9%/CUT 2,36 (confirmare urbanistică). Piesă DTAC corelată cu memoriile de specialitate + piese desenate. Întocmit: arhitect OAR; verificat: verificator atestat MDLPA.
