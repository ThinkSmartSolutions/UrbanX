# MEMORIU TEHNIC GENERAL — SALĂ DE SPORT POLIVALENTĂ (DTAC)

## 1. Date generale

Memoriu general DTAC (Legea 50/1991 Anexa 1) pentru **sală de sport polivalentă competițională** cu tribune, vestiare, anexe. Funcțiune civilă cultură fizică/sport, **sală aglomerată**.

| Element | Valoare |
|---|---|
| Regim | P înalt + tribune + mezanin anexe |
| Sc / Sd | ~2.400 / ~2.850 mp |
| H liber teren | ≥9,00 m (rec. 12,50) |
| Deschidere liberă | 30-36 m (fără stâlpi) |
| Capacitate | ~800-1.200 spectatori |
| Categoria importanță | **B** (aglomerare) |
| Clasa seismică | **II (γI,e 1,20)** |
| Grad RF | II (tendință I la sală aglomerată) |

**Cadru normativ:** Legea 50/1991, 10/1995, HG 907/2016, 766/1997, 350/2001, 372/2005, HG 571/2016; P100-1/2013, CR 0/2012, CR 1-1-3/1-1-4, SR EN 1990-1999/1993/1994; **NP 065-2002** (săli sport), **NP 068-2002** (aglomerări), OMS 119/2014, NP 051/2012, C107, **C125/2013**, EN 12193 (iluminat sportiv); P118-1/2/3, Ordin MAI 129/2016.

## 3. Necesitate și oportunitate

Deficit infrastructură sportivă acoperită (an întreg); cerere școli/cluburi/populație; competiții oficiale (licențiere federații); tribune omologate evenimente. Oportun: programe naționale (CNI/PNRR), regenerare zonă, utilizare mixtă intensivă (școli/cluburi/weekend), SDG sănătate + nZEB.

## 5. Descriere generală

**2 zone volumetrice:** corp sală joc (volum înalt, deschidere mare fără stâlpi, ferme metalice, H liber ≥9 adoptat 12,50) + corp anexă (P+1 parțial: vestiare, GS, birouri, tehnice, fitness, foaier). Tribune longitudinale gradene b.a.

**Teren de joc:** handbal 40×20 (determinant) + siguranță → **44×24 = 1.056 mp**, marcaje suprapuse; pardoseală **parchet sportiv pe suport elastic EN 14904 (A3/A4)** sau PVC omologat.

**Structură:** infrastructură fundații izolate/continue + radier parțial (Df sub îngheț 0,80-1,10, STAS 6054); corp anexă cadre b.a.; **sala joc: stâlpi perimetrali (HEB/beton, pas 6-8) + ferme metalice cu zăbrele deschidere 30-36 m** (S235/S355, h L/12-L/15) + contravântuiri + închideri sandwich + luminatoare N/protejate. Predimensionare fermă L 32: h ~2,15-2,65, q 1,5-2,5 kN/mp, săgeată ≤L/250 = 128 mm. **Zăpadă (CR 1-1-3):** s = γIs·μ·Ce·Ct·sk (acumulări la denivelări/luminatoare critice). **Vânt (CR 1-1-4):** succiune streașină/colțuri + stabilitate răsturnare/lunecare.

**Tribune:** gradene b.a. prefabricate/monolit pe vange înclinate, vizibilitate C ≥60-90 mm, treaptă ~0,80, scaun 0,45-0,50, balustrade ≥0,90-1,00, spații PMR ≥1%. **Vestiare (OMS 119):** min. 4 sportivi (20-25 mp, bancă 0,50 ml/sportiv, 1 duș/3), 2 arbitri, cabinet medical (targă). GS public NP 068 + PMR.

**Confort:** acustică C125 (T ~1,5-2,0 s, fonoabsorbant plafon/pereți); iluminat sportiv EN 12193 (antrenament 300, competiție 500-750, TV 1.000-1.500 lx, U ≥0,5-0,7); termotehnică C107/nZEB (fotovoltaic acoperiș + pompe căldură + recuperare).

## 6. Funcțiuni, zonare, fluxuri

**Separarea totală a fluxurilor (NP 065/068):** sportivi/echipe (vestiar→tunel→teren) / spectatori (casierie→foaier→scări→tribune) / oficiali-arbitri-VIP (dedicat) / presă-TV (cabine) / personal-aprovizionare (serviciu) / ambulanță (acces direct cabinet medical). **Zone:** sportivă (nucleu) / vestiare-anexe / public / administrativ-tehnică.

## 7. Securitate la incendiu

**Sală aglomerată** (>200 sală / >400 cumulat) → **avizare/autorizare ISU** (HG 571/2016). Grad RF min. **II** (rec. I). Compartimentare tehnice/depozite/CT (EI 90-180 + uși EI2 30-90-C).

**Evacuare:** flux 0,60 m, C 70 pers/flux; N 1.100 → F = 1.100/70 ≈ **16 fluxuri → 9,60 m**; min. 2 căi distincte (adoptat 4-6 ieșiri ~2,40 m); uși sensul evacuării + **antipanică EN 1125**; lungime traseu 2 sensuri ≤30-40 m. **Desfumare sală** (trape acoperiș ≥1% pardoseală + aer compensare jos + case scări). **Detecție IDSAI** (P118-3) + hidranți int./ext. + stingătoare + iluminat securitate (SR EN 1838) + rezervă apă + **avertizare vocală EN 54-16** (dirijare mulțime). Acces autospeciale ≥1 latură (3,80 m, 16t).

## 9. Sistematizarea incintei

Acces principal spectatori (piațetă acumulare/dispersie) + acces sportivi/oficiali dedicat (+ parcare autocare) + tehnic/aprovizionare + **ambulanță/intervenție** (direct cabinet+teren). Parcare compartimentată cu fluidizare la eveniment (intrări/ieșiri multiple); PMR lângă acces (3,50×5,00); autocare/taxi/biciclete. Cotă ±0,00 peste teren + pante 1-2% + trotuar gardă; spații verzi ≥25%; evacuare mulțime fără strangulare; împrejmuire + porți control + iluminat + semnalistică.

## 10. Utilități

Apă (racord + ACM pe vârf dușuri simultan + rezervă incendiu); canal menajer + separator grăsimi (dacă alimentație) + pluvial (acoperiș mare, jgheaburi/burlane + retenție/infiltrare); electric (iluminat sportiv mare putere + ventilație + ACM, tablou + **grup electrogen/UPS** securitate) + curenți slabi (sonorizare, scor, IDSAI, control acces, CCTV, date) + priză pământ + paratrăsnet; **HVAC** (pompe căldură/centrală + ventilare cu recuperare + aport aer proaspăt pe ocupare maximă + desfumare integrată); gaze (dacă CT). Instalații sportive (scor, sonorizare arenă, porți/coșuri retractabile).

## 11. Avize și verificări

**Avize (CU):** energie/apă-canal/gaze/telecom, **ISU** (obligatoriu aglomerare), **DSP** (vestiare/ventilație OMS 119), APM (mediu), circulație (Poliția Rutieră — afluență), salubritate, protecție civilă, **aviz federație sportivă** (omologare sală). **Verificare (Legea 10/1995, HG 925/1995)** verificatori atestați MDLPA: **A1/A2** (structură/metal — ferme, tribune), **Bc/Cc** (incendiu/evacuare/desfumare), C (igienă), **D** (sală aglomerată/balustrade/NP 051), **E** (acustică C125), **F** (energie nZEB), **Af** (geotehnic). Dirigenție + referate verificatori.

## 12. Concluzii

Sală de sport polivalentă cu tribune, categoria B, clasa II (γI 1,20), grad min. II RF. Structură deschidere mare (30-36 m ferme metalice) + tribune b.a. verificate la zăpadă (CR 1-1-3) + vânt (CR 1-1-4) critice. **Sală aglomerată** — evacuare ~16 fluxuri/9,60 m, min. 2-4 căi, desfumare ≥1%, antipanică, avertizare vocală (NP 065/068). Separarea fluxurilor (sportivi/spectatori/oficiali/presă/intervenție). POT ~35%/CUT ~0,45; parcare la vârf eveniment ~130 + autocare. Acustică C125 + termotehnică C107/nZEB + PMR NP 051. Cele 6 cerințe A-F. Apt AC (aviz ISU + DSP obligatorii). PTh+DE ulterior. Se completează cu memoriile de specialitate + scenariu securitate + piese desenate.
