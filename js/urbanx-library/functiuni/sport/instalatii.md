# MEMORIU TEHNIC DE INSTALAȚII — SALĂ DE SPORT POLIVALENTĂ (DTAC)

## 1. Date generale și cadru

Instalații pentru **sală de sport polivalentă** (competiții baschet/handbal/volei/futsal/gimnastică + evenimente), ~1.500 spectatori tribune. Cuprinde sanitare, termice, ventilare-climatizare, electrice, PSI, curenți slabi.

| Parametru | Valoare |
|---|---|
| Regim | P + parțial etaj tehnic |
| Ac / Ad | ~3.850 / ~4.900 mp |
| Volum sală joc | ~42.000 mc (H liber ≥12,5) |
| Teren joc / tribune | 44×24 = 1.056 mp / ~1.200 mp (~1.500 locuri) |
| Categorie / clasa / grad | C / II / II RF |

**Aglomerare (P118 art. 1.2.44, >200 pers):** populație vârf eveniment = 1.500 spectatori + 40 sportivi/oficiali + 60 personal TV + 15 permanent = **~1.615 pers** (dimensionare evacuare/ventilare/sanitar public; dușuri/ACM la 40 concentrat).

**Normative:** I9-2022, STAS 1478/1795, SR 1846/EN 12056; I13-2015, SR 1907; I5-2022, SR EN 16798-1/3, NP 008; I7-2011, NP 061-2002, **SR EN 12193** (iluminat sportiv); P118-1999/P118-2-2013/P118-3-2015; NP 065/I6, NTPEE-2018; OMS 119/2014, C107, Legea 372/2005+Mc001, Legea 319/2006. Verificare Is/It/Ie + Ci.

## 2. Instalații sanitare

**Dotare GS public spectatori** (1.500, 50/50, OMS 119): B (750) 5 WC + 6 pisoare + 4 lavoare; F (750) 10 WC + 4 lavoare; +2 WC PMR. **Vestiare** (4 echipe + 2 arbitri): **28 dușuri + 14 lavoare + 10 WC** (40 concentrat).

**Debite (I9):** ΣE ~80,9 echiv.; qc = 0,20·√80,9 + 0,003·80,9 = **2,04 l/s**; vârf dușuri post-meci (28×0,20×0,70) = **3,92 l/s** → **qc,dim = 4,5 l/s (16,2 mc/h)**. Consum zi eveniment ~15.150 l/zi. **Branșament** PEHD De90 (DN80), rețea 2,5-3,0 bar. **H_nec** duș mezanin +4,50: Hg 10,5 + hr 12 + Hu 10 = **32,5 mCA (3,25 bar) > rețea → hidrofor**: 2 pompe VSD (1A+1R) Qp 16,2 mc/h, Hp 35 mCA, P = ρgQH/(3600η) = 2,27 → **2×3,0 kW** + rezervor tampon 5 mc.

**ACM (vârf concentrat dușuri → acumulare):** 28 dușuri × 0,15 × 0,70 = 2,94 l/s; Q_ACM = m·c·ΔT/3600 = 3.500·4,186·35/3600 = **142,5 kW vârf** → **2× boiler bivalent 1.000 l (2.000 l)** + serpentină CT + solar/PC; recirculare ≥50°C + **șoc anti-Legionella 55-60°C**. Vârf 30 min ~1.750 l < 2.000 + aport sursă ✓.

**Canal menajer (I9):** qc,u = qc + qs,max = 4,0 + 2,0 = **6,0 l/s**; coloane De110 (dușuri), colector De160-200 pantă 2%, ventilare peste acoperiș; separator nămol/grăsimi bufet. **Pluvială (acoperiș ~3.850):** Qp = S·Φ·i/10.000 = 3.850·1,0·300/10.000 = **115,5 l/s** → **sistem sifonic (vacuumatic)** sau gravitațional (8 receptoare De110 + coloane De125-160) + **bazin retenție** + valorificare irigare. Rezervă incendiu separată/compartimentată.

## 3. Instalații termice

**Temperaturi:** sală joc **18°C** (efort), tribune 18, **vestiare/dușuri 24**, GS 20, birouri 22, tehnice 10-15; te −18°C (ex.). **Necesar (C107/SR 1907):** sală 42.000·6,5 = 273 kW + vestiare 25 + anexe 38 + ACM 142 vârf/60 mediu = **~396 kW vârf ACM** (~336 kW încălzire+ventilare).

**Sistem sală mare** (evită stratificare la H 12,5): **principal aer cald prin CTA** (integrare încălzire+ventilare, jet descendent dirijat, viteză zonă teren <0,20 m/s) + **panouri radiante tavan** (anvelopă mare fără stratificare); **vestiare radiatoare** + aer cald ventilare (evacuare umiditate).

**Sursă (corp tehnic ventilat):** **2× cazan condensație gaz 200 kW (cascadă, 400 kW)** η >105% + **pompă căldură aer-apă 80 kW** (nZEB sarcină bază) + butelie egalizare + distribuitor 4-5 circuite + vas expansiune 2×300 l. Gaz (NP 065/I6, NTPEE) cu detecție + electrovalvă siguranță CT.

## 4. Ventilare-climatizare

**Aer proaspăt (SR EN 16798-1 cat. II):** 10 l/s·pers (36 mc/h). **Sală 2 regimuri:** antrenament (~50 pers → min. volum 0,5-1 sch/h = 21.000 mc/h guvernant) / **eveniment 1.615 pers → 58.140 mc/h** (verificare CO₂: Q = n·G/(Ci−Ce) = 1.615·20/0,8 = 40.375 < 58.000 ✓). **2× CTA 30.000 mc/h** (recuperare η ≥73% nZEB + baterii C/R + filtre ePM1 60% F7 + **VAV senzori CO₂** modulare antrenament↔eveniment + difuzoare bătaie lungă). Aport termic 1.500 spectatori ~150 kW sensibil → CTA pe **răcire/free-cooling** la eveniment (chiar iarna).

**Vestiare/dușuri (depresiune, evacuare umiditate):** dușuri 15 sch/h (~1.500 mc/h/grup) + vestiare 6-8 sch/h + GS 10 sch/h; cascadă vestiar→duș→evacuare; CTA recuperare + baterie 24°C.

**Desfumare sală** (P118/I5, naturală trape): A_liberă ≥1,5% pardoseală = 0,015·(1.056+1.200) = **33,8 mp** (trape acoperiș automat detecție + manual) + aer compensare jos (v <5 m/s) + cantoane fum. Circulații fără iluminat natural → **desfumare mecanică F400/120**. Comandă centrală detecție + pupitru pompieri.

## 5. Instalații electrice

**Bilanț:** iluminat sportiv 95 + tribune 19,8 + anexe 15,7 + CTA sală 54 + ventilare/desfumare 16,8 + pompe 12,3 + CT 6,7 + prize/forță 14 + curenți slabi 21,6 + ascensor 6,3 = **Pc ~262 kW**; cosφ ≥0,92 → **Sc = 285 kVA**; Ic = 411 A → **transformator 400 kVA** (rezervă) sau JT 400 A.

**Tablouri (radial din TGD):** TGD (contorizare + compensare + ATS) + TEI iluminat sportiv (secționat pe câmpuri, scenarii) + TE forță (CTA/CT/hidrofor) + TV vestiare + **TES securitate** (dublă cale/UPS: pompe PSI, desfumare, iluminat securitate, detecție, EVAC). RCD 30 mA prize + zone umede.

**Grup electrogen** (eveniment/TV + vitale): **250 kVA (200 kW)**, motorină ≥8h, **ATS <15 s**, alimentează securitate integral + iluminat sportiv redus + CTA minim + curenți slabi + TV. Sisteme securitate + UPS proprii (P118/3).

**Priză pământ unică** (protecție+funcțional+paratrăsnet) centură perimetrală OL-Zn 40×4 + electrozi, **Rp ≤1 Ω** (I7); echipotențializare (critic vestiare/dușuri); TN-S. **Paratrăsnet (I7/SR EN 62305):** evaluare risc Nd>Nc → **nivel III (LPL III)** (captare rețea/PDA acoperiș mare + coborâri multiple perimetrale + Rp ≤1 Ω) + **SPD** tip 1+2 TGD + tip 2/3 tablouri securitate/echipamente sensibile.

## 6. Iluminat sportiv (SR EN 12193, NP 061)

| Clasă | Utilizare | Em | U1 |
|---|---|---|---|
| III | antrenament | ≥300 | ≥0,5 |
| II | competiție regională | ≥500 | ≥0,6 |
| I | național/internațional | ≥750 | ≥0,7 |
| TV HDTV | slow-motion | 1.000-1.400 vert. | ≥0,4 vert. |

**Scenarii comutabile:** curățenie 100 (~10 kW) / antrenament 300 (~30) / competiție 750 (~65) / **TV 1.000-1.400 lx (~95 kW)**. **Calcul flux** (teren 1.056, 1.200 lx, Uf 0,55, MF 0,80): Φ = Em·S/(Uf·MF) = 1.200·1.056/0,44 = **2.880.000 lm**; proiectoare LED 700 W/145 lm/W (101.500 lm) → **~60 proiectoare** (redundanță + uniformitate + verticală 4 direcții) pe pasarele tehnice, **GR ≤50** anti-orbire. Cerințe: fără umbre (≥2 direcții/punct), U2 ≥0,7, Ra ≥80 (90 TV), 5.000-5.700 K, **fără flicker** (slow-motion).

**Alte zone:** tribune 200, circulații 100-150, vestiare 300 (IP44), dușuri 200 (IP65), birouri 500, exterior 20-50. LED.

**Iluminat securitate (aglomerare — critic):** evacuare ≥1 lx ax (0,5 bandă) + **anti-panică ≥0,5 lx la sol pe toată suprafața tribune/teren** (evită busculadă) + continuare lucru medical/comandă 15 lx; autonomie ≥1h, intrare ≤5 s; acumulatori proprii/sursă securitate + pictograme.

## 7. PSI (P118)

**Scenariu securitate** (Ordin MAI 129/2016) → **aviz/autorizație ISU**; aglomerare >1.600, grad II RF, risc mic-mijlociu, dar **panică critică**.

**Evacuare (P118-1999):** flux 0,70 m, C ~50 pers/flux (săli aglomerate, ~2,5 min); N 1.615 → **~33 fluxuri → 23,1 m lățime total** pe **min. 4 ieșiri** distincte (sensuri opuse, ≥2 fluxuri/ieșire, uși sensul evacuării + bare antipanică fără praguri); vomitorii tribune; înfundat ≤20 m / 2 direcții ≤40 m.

**Detecție IDSAI (P118-3):** centrală adresabilă (48h veghe + 30 min alarmare) + optice anexe/vestiare + **bariere optice liniare/aspiraționale ASD** sală mare + butoane + sirene+flash + interfațare (desfumare/oprire ventilare/deblocare acces fail-safe/pompe/iluminat securitate).

**Stingere (P118-2):** hidranți interiori **2 jeturi = 4,2 l/s** (DN50, furtun 20 m) + exteriori **10 l/s** (0,7 bar); **rezervă Vri = (4,2·10·60 + 10·180·60)/1000 = 110,5 mc** → **rezervor 110-120 mc** + stație pompare (activă+rezervă+pilot, dublă alimentare/GE). Sprinklere neobligatorii pe sală (GRF II risc mic), la depozite risc după scenariu.

**Alarmare vocală EVAC (SR EN 54-16/24 — critic panică):** mesaje preînregistrate multilingv **STI ≥0,5** + zonare (evacuare dirijată etapizată) + cabluri E30/E90 + baterii 30 min + prioritate asupra sonorizării. Stingătoare (P6/CO₂ tablouri, 1/150 mp); compartimentare tehnice EI; gaze detecție + electrovană.

## 8. Curenți slabi

**Sonorizare** (dublă funcție eveniment + suport EVAC): line-array/cluster central + acoperire tribune, **STI ≥0,50** (≥0,60 eveniment), 95-100 dB(A), tratament acustic **RT60 1,5-2,0 s** (esențial STI). **Tabelă scor** electronică (cub central multivalent: scor/timp/posesie 24s/faulturi) + LED perimetrale. **CCTV** IP HD/4K (tribune identificare + intrări/teren/perimetru/parcări/acces vestiare — NU interior), NVR ≥30 zile RAID + dispecerat + analiză aglomerări. **Control acces/ticketing** turnicheți QR/RFID + carduri zone restricționate + **deblocare fail-safe la alarmă**. **Rețea date** Cat.6A/fibră + WiFi mare densitate + puncte TV broadcast (4 direcții camere + regie/OB + fibră) + telefonie IP + internet redundant + NTP.

## 9. nZEB (Legea 372/2005)

**Fotovoltaic acoperiș** (~2.000 mp util, module 210 W/mp 21%): **~400 kWp** → E = 400·1.150 = **460.000 kWh/an** (autoconsum iluminat/CTA + prosumator). **Recuperare CTA η ≥73%** + **recuperare ape uzate dușuri** (schimbător pe canal → preîncălzire ACM, consum concentrat 15-20%) + free-cooling. **Pompă căldură aer-apă 80 kW** COP ≥3,5 (bază). **LED sportiv 145 lm/W** (−40% vs. metal-halide + control DALI scenarii) + **VAV CO₂** (−40% ventilare antrenament). → **nZEB clasa A**.
