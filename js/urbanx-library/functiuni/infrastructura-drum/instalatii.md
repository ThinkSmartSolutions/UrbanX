# MEMORIU SCURGERE APE + SIGURANȚĂ + SEMNALIZARE — DRUM (DTAC)

*(echivalentul „instalațiilor" pentru infrastructura rutieră). Sector ~1,00 km.*

## 1. Obiect și cadru

Echiparea drumului: scurgere ape + siguranță circulație + semnalizare (verticală/orizontală/temporară) + iluminat.

**Normative:** Legea 10/1995, 50/1991, OG 43/1997, OUG 195/2002; **STAS 4068 (debite max), STAS 10796 (șanțuri/rigole/drenuri), STAS 9312 (subtraversări), SR 1846 (canalizare)**; **SR EN 1317-1/5 (parapete), AND 594, SR EN 12767 (stâlpi pasivi)**; **SR 1848-1 (indicatoare) + 1848-7 (marcaje), HG 1391/2006**; **SR EN 13201 (iluminat), NP 062-02**.

## 2. Scurgerea apelor

Evacuare gravitațională: pantă transversală **i_T 2,5%** (carosabil → rigole) + longitudinală **i_L ≥0,5%** (excepțional 0,25% pereat). **Debit pluvial (metoda rațională): Q = m·i·S·φ** (m 0,8 reducere, i intensitate ploaie l/s·ha frecvență 1/1-1/2 ani, S bazin ha, φ scurgere). φ: carosabil 0,85-0,95, acostament 0,50-0,60, taluz 0,10-0,30. **Ex.** carosabil 100×7 = 0,07 ha, φ 0,90, i 130: Q = 0,8·130·0,07·0,90 = **6,55 l/s** → acoperitor ~15 l/s/tronson.

## 3. Dimensionare hidraulică șanțuri/rigole (Manning)

**Q = (1/n)·A·R^(2/3)·i^(1/2); v = Q/A; R = A/P.** n: pământ 0,025-0,030, înierbat 0,030-0,035, pereat piatră 0,020-0,025, **beton 0,013-0,016**. **Șanț trapezoidal** b 0,40, h 0,40, taluz 1:1, i 1%, beton (n 0,015), umplere 0,30: A = (0,40+0,30)·0,30 = **0,210 mp**; P = 0,40+2·0,30·√2 = **1,249**; R = **0,168**; **Q_cap = (1/0,015)·0,210·0,168^⅔·0,01^½ = 0,426 mc/s = 426 l/s ≫ 15 l/s calcul** ✓; v = 0,426/0,210 = **2,03 m/s** (>autocurățire 0,4, <eroziune beton 6). Pante >4% → praguri rupere pantă.

| Situație | Dispozitiv |
|---|---|
| Debleu/la nivel | șanț trapezoidal betonat 0,40×0,40 |
| Rambleu jos | rigolă triunghiulară pereată |
| Urban (borduri) | rigolă acostament + guri scurgere |
| Pante mari | rigolă trepte/praguri |

## 4. Podețe și traversări

Traversare curs/talveg/șanț. Tubular Ø400-1000 (șanțuri) / dalat l 1,0-5,0 (talveg). **Curgere plină: Q = μ·A·√(2gH)** (μ 0,6-0,8). Ex. Ø800, H 0,5, μ 0,7: A = π·0,8²/4 = 0,503; Q = 0,7·0,503·√(2·9,81·0,5) = **1,10 mc/s** ≫ calcul → min. **Ø500** (mentenanță) + timpane/aripi/radier antiafuiere.

## 5. Drenuri + canalizare pluvială urbană

**Drenuri** (ape subterane la debleu/freatic ridicat): tub perforat Ø150-200 + material filtrant + geotextil, i ≥0,3% → coboară freatic sub pat. **Urban:** rigole acostament → **guri scurgere** (sifon + depozit, la puncte joase obligatoriu, interdistanță 30-50 m, suprafață 300-500 mp/gură) → **colector pluvial** (PVC/PP SN8/beton, i ≥0,3%, v ≥0,7 m/s autocurățire) + cămine vizitare ≤60 m (SR 1846).

## 6. Siguranța circulației — parapete (SR EN 1317)

**Nivele reținere:** N1/N2 (secundare) / H1 (naționale) / H2-H3 (autostrăzi/poduri) / H4 (critice). **Obligatoriu:** rambleu ≥3,0 m + obstacole laterale (zonă siguranță 2-4 m) + poduri/podețe/ziduri + curbe/pante periculoase + ape adânci/CF paralel. **Adoptat:** traseu curent rambleu 3-4 m parapet metalic **N2/H1**, la podețe/ziduri **H2** + tranziție, terminații ancorate/atenuatoare. **E_c = ½·M·v²·sin²α** (energie impact test). Stâlpi cedanți SR EN 12767 (zone fără parapet).

## 7. Semnalizare verticală (SR 1848-1)

| Categorie | Formă/culoare |
|---|---|
| Avertizare | triunghi margine roșie fond alb |
| Reglementare prioritate | STOP octogon / cedează triunghi inversat |
| Interdicție | cerc margine roșie (viteză, depășire) |
| Obligare | cerc albastru |
| Orientare/informare | dreptunghi albastru/verde |

Montare: h 1,50-2,20 (extravilan) / ≥2,50 peste trotuar (urban), lateral 0,50-2,00; presemnalizare funcție viteză (150-250 m); folie retroreflectorizantă clasa 2 (HI)/3 (DG). Program: intrare (viteză) + curbe + intersecții (cedează/STOP) + treceri pietoni + ieșire.

## 8. Semnalizare orizontală (SR 1848-7)

Longitudinale axiale (discontinuă depășire permisă / continuă interzisă / dublă) + marginale + transversale (STOP, cedare, treceri pietoni zebra) + diverse (săgeți, hașuri). Lățime linie **12 cm**; discontinuă interurban 3/6 m (3/3 la intersecții); vopsea ecologică + microbile (R_L ≥150 mcd/mp/lx uscat) sau termoplastic; antiderapare SRT ≥45. Linie continuă în curbe vizibilitate redusă + apropiere intersecții.

## 9. Semnalizare temporară șantier

Fond galben (normativ CNAIR): presemnalizare lucrări + limitări progresive (70→50→30) + devieri/circulație alternantă (semafoare mobile/piloți) + delimitare (conuri/balize/panouri/garduri + lămpi galbene noapte). **Plan semnalizare temporară avizat** administrator drum + Poliția Rutieră.

## 10. Iluminat public (SR EN 13201)

**Clase M** funcție categorie/viteză: M1 (2,0 cd/mp) / M2 (1,5) / **M3 (1,0, U_o ≥0,40 — urban/colector)** / M4 (0,75); zone conflictuale clase C. **Adoptat M3** (TI ≤15%). Stâlpi H 8-10 m, interdistanță 30-40 m (e/H 3-4), dispunere unilaterală/bilaterală, LED 3000-4000K IP66; calcul luminotehnic (luminanță + uniformitate + TI, SR EN 13201-3); rețea subterană + telegestiune + priză pământ. **Stâlpi cedanți SR EN 12767** (zone fără parapet).

## 11. Echipamente

Borne km/hm + delineatori (20-50 m) + butoni retroreflectorizanți + catadioptri parapet + panouri/oglinzi intersecții.

## 12. Concluzii + verificare/avize

Scurgere gravitațională (i_T 2,5%, i_L ≥0,5%) + șanțuri betonate 0,40×0,40 (**Q_cap 426 ≫15 l/s Manning**) + podețe (min. Ø500, verificate) + drenuri + urban guri scurgere/canalizare (SR 1846). Debit rațional Q = m·i·S·φ + capacitate Manning (v autocurățire<v<eroziune). Parapete **N2/H1 traseu, H2 podețe** (SR EN 1317) + stâlpi cedanți SR EN 12767. Semnalizare verticală (SR 1848-1) + orizontală (SR 1848-7) + temporară (plan avizat). Iluminat **M3** (SR EN 13201). **Verificare Af (drumuri) + Bf + Ie (iluminat)** verificator atestat. **Avize:** administrator drum/CNAIR, **Poliția Rutieră** (proiect semnalizare definitivă+temporară), operator apă-canal (racord pluvial), operator energie (iluminat), **ANAR** (gospodărirea apelor, evacuări/podețe). RTE atestat + recepție faze determinante.
