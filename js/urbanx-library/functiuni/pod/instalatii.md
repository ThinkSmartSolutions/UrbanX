# MEMORIU ECHIPAMENTE + HIDRAULICĂ / AFUIERE — POD RUTIER (DTAC)

*(echivalentul „instalațiilor" pentru pod). Pod 3×40 m peste râu.*

## 1. Obiect și cadru

Componente hidraulice + echipamente pod + protecții anticorozive + monitorizare, complementar rezistenței. **Normative:** **CD 99 (afuieri), STAS 4068/4273 (debite + clase importanță hidrotehnică), PD 95, AND 522**; **SR EN 1317 (parapete), SR EN ISO 12944 (anticoroziv oțel), SR EN 1504 (protecție beton)**; **Legea apelor 107/1996 (AGA)**; SR EN 1991-1-6 (execuție).

## 2. Hidraulica — debit și niveluri

**Clasa importanță hidrotehnică (STAS 4273, pod categoria B):** debit calcul **1% (T 100 ani)** + verificare **0,5% (T 200)**. Ex.: **Q_1% 520 mc/s** (verificare 610), Q_med 28. **NAE (1%)** din curba de cheie: talveg 100,00 → **NAE 105,20 mdMN**, h_m 3,40, luciu ~95 m, secțiune ~260 mp, **v = Q/A = 520/260 = 2,00 m/s** (albie minoră contractată ~2,4). Manning: v = (1/n)·R^⅔·i^½ (n 0,035 natural).

## 3. Secțiune scurgere + înălțime liberă

**Contracție pile:** μ = 1 − Σb_pile/L = 1 − 2·1,60/120 = 0,973 (remuu <5 cm). **Înălțime liberă = z_intrados − z_NAE ≥ rezervă 0,50-1,50 (adoptat 1,00 plutitori/gheață):** NAE 105,20 + 1,00 = intrados min. 106,20; proiectat **106,50 → H_liber 1,30 m >1,00** ✓.

## 4. Afuierea (CD 99 — CRITIC)

**Totală = generală + locală.** **Generală:** h_af,gen = h0·(v/v_cr)^n − h0; h0 3,40, v 2,4, v_cr 1,3 (d50 20 mm), n 1,15 → **3,33 m**. **Locală pilă (HEC-18/CD 99):** y_s/b = 2,0·K1·K2·K3·(y1/b)^0,35·Fr^0,43; b 1,60, y1 6,73, Fr = 2,4/√(9,81·6,73) = 0,295, K1 1,0/K2 1,1/K3 1,1 → y_s/b = 2,40 → **y_s = 3,84 m**. **Culee** (Froehlich) ~2,5-3,0 m. **Total = 3,33 + 3,84 = 7,17 m (→7,50)** → cota afuiere **92,50 mdMN** (talveg 100 − 7,50).

## 5. Protecția fundațiilor la afuiere

**Fundare sub afuiere:** piloți Ø1,20 vârf **82,00 mdMN → 10,50 m sub afuiere 92,50** (frecare doar sub cota afuiere). **Anrocamente (Isbash/CD 99):** d50 ≥ v²/(2g(s_s−1)C²) = 2,4²/(2·9,81·1,65·0,86²) = **0,24 → adoptat 0,40-0,60 m**, grosime ≥2·d50 = 1,0 m + filtru geotextil+balast, rază ≥2b în jurul pilei. **Radier protecție** culee/rampe (pereu/dale + casiuri).

## 6. Echipamentele podului

**Hidroizolație cale** (membrană bituminoasă armată/PUR, aderență ≥0,6 MPa, rezistă 160°C). **Cale asfaltică** (uzură SMA BA16 4 + binder BAD22,4 6 + protecție mastic 2 = **12 cm**), pantă 2,5%. **Rosturi dilatație** modulare etanșe ≥160 mm (profile sinusoidale zgomot redus). **Guri scurgere** Ø150-200 interax ≤20 m (Q_p = C·i·A = 0,9·150·0,096 = 13 l/s → Ø150 suficient) + casiuri (nu apă pe elevații). **Parapete SR EN 1317:** siguranță **H2/H3** (severitate A/B, W verificat) zincate + lisă b.a. + **pietonal h ≥1,10 m** + borne/marcaje reflectorizante. **Iluminat** LED (interax 25-30 m, canalizație în lise + priză pământ). **Cale vizitare/inspecție** (pasarelă sub tablier + nișe culee acces aparate/rosturi + scări zincate + iluminat inspecție + spații monitorizare). **Racord terasament** plăci racordare 4-6 m (anti-„bump").

## 7. Protecție anticorozivă

**Beton:** acoperire mărită **XD3 cnom 55 mm** + beton a/c ≤0,45 XF4 aer antrenat + protecție suprafață (silan/siloxan SR EN 1504-2) + eventual protecție catodică. **Oțel (variantă mixtă/parapete, SR EN ISO 12944 C5-VH >25 ani):** **zincare termică ≥85 μm + duplex** (grund epoxi-zinc 60 + intermediar epoxi 120 + finisaj PUR 60 = ≥240 μm), pregătire Sa 2½; ancore inox A4.

## 8. Monitorizare (AND 522)

**Urmărire curentă** (inspecție anuală: fisuri/coroziune/cale/rosturi/aparate + după viituri/cutremure). **Specială instrumentată:** **batimetrie periodică albie la pile (CRITIC — verificare afuiere reală după viituri)** + traductoare deplasare rosturi/aparate + tasări topo + eventual SHM (accelerometre zonă seismică). Carte tehnică + jurnal evenimente + program întreținere (hidroizolație/cale 12-15 ani, aparate 25-30 ani, anticoroziv periodic).

## 9. Avize

**Aviz gospodărirea apelor AGA (Apele Române/ABA — CRITIC**, pod peste apă: verifică Q, NAE, afuiere, secțiune, protecții, Legea 107/1996 — condiționant lucrări albie) + CNAIR/administrator drum (racord/gabarite) + acord mediu APM (impact curs/habitat) + ABA regim albie (deviere temporară execuție) + deținători rețele + referat verificator (A2/Af/hidro).

## 10. Concluzii

Scurgere **Q_1% 520 mc/s** (verificare 0,5%), **H liber 1,30 >1,00 m** peste NAE, remuu <5 cm (contracție pile 2,7%). **Afuiere totală 7,17 (→7,50) m**, cotă 92,50; piloți vârf 82,00 → **10,50 m sub afuiere** + anrocamente d50 0,40-0,60. Echipamente (hidroizolație + cale + rosturi ≥160 + guri + parapete H2/H3 SR EN 1317 + pietonal ≥1,10 + iluminat + cale inspecție) + anticoroziv (beton XD3 + oțel duplex C5-VH) → durabilitate + siguranță **100 ani**. Program urmărire AND 522 (**batimetrie afuiere pile**). Apt pentru **aviz gospodărirea apelor** + autorizare, cu condițiile avizelor + monitorizare.
