# MEMORIU DE ARHITECTURĂ / GEOMETRIE POD (DTAC)

## 1. Alcătuirea generală

Pod = **suprastructură** (preia + transmite trafic la reazeme) + **infrastructură** (transmite terenului) + **aparate reazem** + **cale + echipamente**.

| Grup | Element | Rol |
|---|---|---|
| Suprastructură | grinzi principale BP + placă cale + antretoaze | încovoiere long. + distribuție transv. |
| Infrastructură | culee (2) + pile (2) + fundații (piloți) | reazeme + transmit teren |
| Legături | aparate reazem + rosturi dilatație | reacțiuni/deplasări |
| Cale | hidroizolație + asfalt + parapete + guri + borne | rulare/siguranță/drenaj |

**Suprastructură:** 6 grinzi prefabricate BP interax 2,00 m (h 1,80-2,00 deschidere 40 / 1,20 deschideri 24) + placă colaborantă 20-25 cm continuizată peste pile + antretoaze. B_t = 5·2,00 + 2·1,00 consolă = **12,00 m**. **Culee** masiv-cadru b.a. (cuzineți + zid gardă + ziduri întoarse/aripi + fundație piloți Ø1,08). **Pile** lamelare/ovoidale (reduc afuierea) + riglă + radier pe piloți Ø1,20 sub afuiere. **Aparate reazem** neopren fretat (fix pot bearing) + **rosturi** modulare (Δ_rost = Δ_termic + Δ_contracție/fluaj + Δ_seismic; Δ_termic = α·ΔT·L_dil = 10⁻⁵·50·89.600 = 44,8 mm → rost ≥80-100 mm sau ≥160 la 3×40).

## 2. Gabarite

**Pe pod (liberă trecere):**

| Element | Lățime (m) |
|---|---|
| Parapet siguranță + lisieră (×2) | 2×0,50 |
| Trotuar (×2) | 2×1,25-1,50 |
| Bandă încadrare (×2) | 2×0,50 |
| Bandă circulație (×2) | 2×3,50 |
| **Total tablier B_t** | **12,00** |

Înălțime liberă pe pod ≥5,00 m (tablier deschis). **Sub pod (hidraulic):** L_scurgere = L_între_culee − Σb_pile (ex. 88 − 2·1,50 = **85,00 m**); **H_liber = C_intrados − NAE = 1,00 m** (gardă). Nu navigabil/rutier.

## 3. Geometria căii pe pod

**Plan:** aliniament (traversare dreaptă α 90°, sau esbiaj) în continuitate cu drumul; racord fără curbe pe pod (în curbă → supralărgire + supraînălțare). **Profil longitudinal:** pantă ≤2,5% (favorabilă scurgere), min. 0,5-1,0%, racordări verticale la capete. **Profil transversal:** pantă acoperiș **2,5%/versant** spre guri scurgere; în curbă = supraînălțare (dever).

## 4. Echipamente

**Parapete (SR EN 1317):** siguranță (lisieră) **H2/N2** (nivel reținere; H2 recomandat pod — cădere în apă) + pietonal H ≥1,00-1,10 m (umplutură verticală, STAS 1948-1) + terminale/tranziții. Alegere din energie impact E_c = ½·M·v²·sin²α. **Rosturi dilatație** modulare etanșe ≥80-160 mm. **Hidroizolație + cale asfaltică** (membrană + protecție + binder + uzură = 10-12 cm). **Guri scurgere** (interdistanță 15-25 m, d = Q_admis/q_aport) + casiuri (rampe/sferturi con). **Borne + iluminat** (console/stâlpi parapet, tubulatură înglobată) + tubulaturi tehnice trotuare.

## 5. Racord cu terasamentul

**Sferturi de con** la culee (taluze racordate, protejate peree/piatră/dale, pantă **1:1,5-1:2**). **Plăci de racordare** b.a. (evită „saltul" din tasare terasament spate culeu): **L_placă = (0,75-1,00)·H_culee ≥3,00-6,00 m**; culeu H 6,0 → L 5,00 m pantă ≤10%, armate pt. trafic pe deschidere liberă.

## 6. Estetică

Proporții zvelte (h/L ~1/22) + pile lamelare (transparență hidraulică) + placă continuizată (linie fluidă, minim rosturi) + beton aparent cofraje îngrijite culori neutre + parapete ritm regulat (metal siguranță + mână curentă pietonală) + iluminat discret în parapet + racord maluri sferturi con înierbate/pereu.

## 7. Concluzii (cerințe alcătuire)

Gabarit pe pod **B_t 12,00 m** (2×3,50 + încadrare + trotuare + parapete) + profil 2,5% + H liber ≥5,00; gabarit sub pod **L_scurgere 85,00 m + H_liber 1,00 m** peste NAE (intrados +43,80/+106,50 mdMN); geometrie cale (aliniament, pante scurgere); echipamente **parapete H2/N2 (SR EN 1317)** + rosturi ≥80-160 mm + hidroizolație+asfalt + guri 15-25 m; racord **sferturi con 1:1,5-1:2 + plăci racordare L 5,00 m**; integrare estetică (siluetă zveltă, pile lamelare, continuizare). Respectă STAS 2924 (gabarite), STAS 3221 (clasa E), SR EN 1991-2 (LM1-LM4), SR EN 1317, AND 522/PD 165. Cerințe L10/1995.
