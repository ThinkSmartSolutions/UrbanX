# MEMORIU TEHNIC GENERAL — SPAȚIU COMERCIAL / SUPERMARKET (DTAC)

## 1. Date generale

Memoriu general DTAC (Legea 50/1991 Anexa 1) pentru **supermarket alimentar cu autoservire** + depozit + back-office + parcare, regim P (mezanin parțial P+1).

| Element | Valoare |
|---|---|
| Teren / Scd | 8.500 / ~2.900 mp (+ mezanin 120) |
| Sală vânzare Sv | 1.600 mp |
| Categoria importanță | **C — normală** (HG 766/1997) |
| Clasa seismică | **II (γI,e 1,2)** — aglomerări de persoane |
| Grad RF | **II** |
| Risc incendiu | mediu (420-840 MJ/mp vânzare) / >840 local depozit |

> **Categoria importanță ≠ clasa seismică:** categoria C (HG 766) dar clasa **II** (P100-1 §4.4.5 — sala de vânzare = aglomerări >50 pers/încăpere). Acte normative diferite.

**Cadru normativ:** Legea 50/1991, 10/1995, HG 907/2016, HG 766/1997, 350/2001, Legea 372/2005, OUG 195/2005 + Legea 211/2011 (deșeuri); P100-1/2013, CR 0/2012, CR 1-1-3/1-1-4, CR 6/SR EN 1992/1993/1994, NP 112/2014; P118-1/2/3, **NP 068-02** (aglomerări), C107, NP 051/2012, I5/I7/I9/I13, GP 063/OMS 119/2014, NTPA 002.

## 3. Necesitate și oportunitate

Deficit GLA comercial modern (RO ~250-290 mp/1.000 loc vs UE ~1.100); arie captare rază 3-5 km / 8-10 min = 12.000-25.000 loc. Oportunitate: urbanistic compatibil + front stradal, economic (40-70 locuri muncă), social (proximitate + PMR 100%), racordabil utilități, nZEB.

## 5. Descriere generală — structură mixtă

Infrastructură beton armat + **suprastructură cadre metalice** (deschideri mari, rapid, greutate redusă).

| Element | Soluție |
|---|---|
| Fundații | izolate cuzinet + bloc sub stâlpi metalici + grinzi soclu + placă pe sol |
| Vertical | stâlpi HEA/HEB S275/S355 + buloane ancoraj |
| Orizontal/acoperiș | grinzi/ferme metalice, deschideri 12-16 m, travee 6-8 m |
| Contravântuiri | verticale + orizontale (seism/vânt) |
| Închideri | panouri sandwich + soclu beton |
| Acoperiș | terasă/șarpantă + sandwich, pantă 3-5%, termo-hidro |
| Pardoseală | placă b.a./fibre, portanță 3-5 t/mp depozit, antiderapant |

**Deschideri libere mari** sală vânzare (fără stâlpi deranjanți) = justificarea soluției metalice. Zone: sală 1.600 (H liber 3,5-4,0), depozit 480 (paletizat), recepție+rampă 160 (dock leveler +1,10-1,20), camere frig 150 (+2/+4 și −18/−22, sandwich frigorific), tehnice 210 (CT, tablou+grup, pompe sprinkler+rezervor, ventilare), birouri+mezanin 120 (+ money room securizat), vestiare/GS 95 (OMS 119), GS public+PMR 40.

## 6. Zonare și fluxuri

**Separarea strictă marfă/client** (OMS 119 + siguranță). **Marfă:** camion→rampă/recepție→sas→depozit/frig→reaprovizionare→sală. **Client:** parcare→intrare/sas→sală→case→ieșire. **Deșeuri:** colectare selectivă→presă baloți→platformă gospodărească curte tehnică→ridicare pe traseu marfă (nu prin sală).

**Lanț de frig (HACCP):** recepție rapidă→camere frig; vitrine perimetrale pe circuit separat cu **alimentare de rezervă (grup)** anti-pierdere marfă; monitorizare temperatură + alarmare.

## 7. Securitate la incendiu (Cerința B)

Grad RF **II** (structură metalică protejată R60-90), risc mediu/mare local, densitate sarcină termică 420-840 (>840 depozit), N ≈ **534 pers**.

**Compartimentare:** aria mărită cu sprinklere (P118-1 Tab.3.2.4); separare sală/depozit/tehnice pereți EI 120-180 + uși EI 90-120 autoînchidere.

**Evacuare:** U = N/70 = 534/70 ≈ 7,6 → **8 unități trecere** → L_evac ≥ 8×0,60 = **4,80 m**; min. 2 ieșiri distincte → **3 ieșiri** (≥5,40 m = 3×1,80); distanță două direcții ≤40 m / un sens ≤20 m; uși în sensul evacuării + bare antipanică; iluminat securitate ≥1h.

| Instalație | Prevedere |
|---|---|
| Detectare IDSAI | acoperire integrală (P118-3) |
| Sprinklere | sală + depozit (P118-2) |
| Hidranți interiori | 2 jeturi simultane |
| Hidranți exteriori | incintă/rețea |
| Rezervă + pompare | rezervor + pompe (activă+rezervă+pilot) |
| Desfumare | trape/mecanică sală (spațiu aglomerat) |
| Grup electrogen | vitale + lanț de frig |

## 9. Sistematizarea incintei

**Acces auto client** din arteră cu buclă + separare intrare/ieșire; **acces marfă** distinct spre curte tehnică (semiremorcă R giro ≥12,0, alee ≥6,0, dock leveler); **drop-off** sub copertină (taxi/PMR); trotuare ≥1,5 + traversări + ghidaj tactil PMR. Parcare cu pante ≥1,5% → rigole → separator hidrocarburi; adăposturi cărucioare (≥3); iluminat LED + CCTV; sistematizare verticală + bazine retenție pluvial; împrejmuire + porți.

## 10. Utilități

Apă (branșament + gospodărie consum + rezervă incendiu, I9/P118-2); canal menajer (NTPA 002) + pluvial (separator hidrocarburi + bazin retenție + deversare controlată); electric MT/JT + **post trafo** (frig+HVAC) + tablou; **grup electrogen** (frig+incendiu+iluminat securitate); HVAC (CT/pompe căldură + rooftop + **recuperare căldură de la agregate frig**); gaze (dacă e cazul); instalație frigorifică (agregate curte tehnică, HACCP); telecom/CCTV/antiefracție. **Putere instalată ~350-550 kW** (dominant frig+HVAC+iluminat).

## 12. Concluzii

Supermarket autoservire P (+mezanin), categoria C / clasa II seismică / grad II RF. Structură mixtă (fundații b.a. + suprastructură metalică) → deschideri libere mari. POT 34,1%/CUT 0,34 sub maxime; verzi 15,9%. Parcare 64 (1/25 mp Sv) + 5 PMR + cărucioare. Separare fluxuri marfă/client/deșeuri + lanț de frig (grup rezervă, OMS 119). Securitate incendiu integral (evacuare ~534 pers, 8 unități trecere / 4,80 m, 3 ieșiri, sprinklere, IDSAI, desfumare) sub aviz ISU. PMR 100% (NP 051). nZEB (recuperare frig). Verificare A-F + avize → apt AC. Se completează cu memoriile de specialitate + piese desenate + scenariu securitate.
