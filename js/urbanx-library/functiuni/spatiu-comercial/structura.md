## 2. Sistemul structural

**Hală metalică parter deschidere mare:** cadre transversale (interax 6 m, stâlpi încastrați + rigle cu inimă plină + vute / ferme zăbrele) + contravântuiri verticale longitudinale + contravântuiri acoperiș (diafragmă) + pane Z/C + învelitoare sandwich + **mezanin compozit** parțial.

**Justificare metal (12-24 m):** greutate proprie mică (25-45 kg/mp → masă seismică mică), execuție rapidă, deschideri libere economice (fermă h ≈ L/15-20), ductilitate. Soluție A: cadru portal inimă plină cu vute.

**Regularitate:** mezanin parțial → **neregulat în plan + elevație** → q redus ×0,8 + **analiză modală cu spectre** + verificare torsiune.

## 3. Factor de comportare q

**DCM** (transversal cadre necontravântuite + longitudinal CBF în X). Referință P100-1 tab.6.3: cadre q = 4·(αu/α1) → adoptat 4,0; CBF X 4,0. **Neregularitate elevație −20%:** q = 4,0·0,8 = 3,2 → **adoptat q = 3,0** ambele direcții. (DCL q 1,5-2,0 posibil dar forțe ×1,5-2 → se preferă DCM.)

## 4. Placa pardoselii comerciale/industriale

Cerințe: cărucioare + **motostivuitor** (2,5-3,5t) depozit + rafturi (racking) + planeitate + uzură. **Placă pe pat elastic** (Westergaard): uzură quartz 3 mm / **placă C30/37 fibre+plasă 180 mm sală / 200 depozit** / folie PE / XPS (camere frig) / balast.

**Dimensionare (Westergaard, depozit, k=50 MN/mc, P roată 31 kN):** ℓ = [E·h³/(12(1−ν²)k)]^0,25 = [2,64·10¹¹/0,586]^0,25 ≈ **810 mm**; M = P/4·(1+ν)·[ln(ℓ/a)+0,5] = 8.912·2,59 = **23,1 kNm/m**. Capabil: fibre 10,0 + **plasă Ø8/150** (21,6) = **31,6 > 23,1** ✅. Străpungere raft (P 40 kN): v_Ed = 40.000/(2.704·165) = 0,090 < v_Rd,c 0,45 ✅.

**Rosturi:** contracție 5-6 m (tăiere 1/3 la ≤24h), turnare (gujoane Ø20/300), dilatare perimetral (bandă 10 mm), izolare stâlpi (placă flotantă). **Planeitate FM2** (SR EN 15620, ≤4 mm/2 m). **Camere frig negativ:** XPS ≥300 kPa + **antiîngheț sol** (cablu/glicol) + placă flotantă (anti frost heave).

## 6. Calcul seismic

**Masă** (acoperiș 0,78 + ψE·Q + structură 0,35 pe 2.100 + mezanin 4,0 pe 240 + închideri): **W ≈ 4.212 kN → m 429 t**. **T1** = 0,085·7,2^0,75 = 0,37 empiric (modal **0,55 transversal / 0,40 long**), TB<T1<TC → **Sd = ag·β0/q = 0,30·2,5/3,0 = 0,25g**. **Fb = γI·Sd·m·λ = 1,0·0,25·429·0,85 = 894 kN** (acoperitor λ=1,0 → **~1.050 kN**, c = 0,25). Distribuție: acoperiș 803 + mezanin 247 kN.
