## 1. Date generale și tema de proiectare

Memoriu de arhitectură DTAC pentru **spital/clinică multidisciplinară cu spitalizare continuă, S+P+4E**, cadre beton armat.

| Element | Valoare |
|---|---|
| H cornișă / max | 19,50 / 21,00 m |
| Ac / Ad | 2.350 / 13.100 mp (S+P+4E) |
| Capacitate | **220 paturi** |
| Categoria importanță | **B** — deosebită (HG 766/1997) |
| Clasa seismică | **I, γI = 1,4** (P100-1/2013 tab.4.2) |
| Grad RF | **I** (parțial II anexe) |
| Risc incendiu | mic spitalizare / mediu bloc alimentar+spălătorie |

**Justificare clasa I:** adăpostește persoane care nu se pot evacua singure (imobilizați, ATI, bloc operator) + trebuie funcțional post-seism → γI 1,4 (+40% forță seismică). Impune arhitectural: regularitate plan/vertical, rosturi seismice, evitare console mari + etaje flexibile.

**Cadru normativ:** Legea 50/1991, 10/1995, **NP 015-1997**, **Ordin MS 914/2006** (circuite + spații), **Ordin MS 1096/2016** (sterilizare SPD), OMS 119/2014, NP 051/2012, C107, P118-1/2/3, C125/2013, GP 063-2001 (bucătării), SR EN ISO 7730. Verificare A1+A2/B1/Cc/D/E/F.

## 5. Circuitele funcționale (Ordin MS 914/2006)

Separare strictă (prevenire IAAM); intersecțiile inevitabile → decalare timp + sasuri/filtre.

| Circuit | Conținut | Regim |
|---|---|---|
| Aseptic | material steril, personal echipat, bolnav pregătit | presiune pozitivă |
| Septic | deșeuri, lenjerie murdară, instrumentar utilizat | presiune negativă |
| Bolnav | internare/transfer/externare | ascensor pat dedicat |
| Personal | prin vestiare-filtru | separat de public |
| Vizitatori | acces controlat, ore vizită | separat de flux medical |
| Steril | SPD → bloc operator/secții | protejat |
| Deșeuri | selectiv (galben infecțios/negru menajer) | ascensor murdar |
| Lenjerie | curată ≠ murdară | flux dublu |

**„Marche en avant" (SPD, OMS 1096/2016):** flux liniar unidirecțional [recepție murdar → spălare-dezinfecție → |barieră| → împachetare → autoclavare → |barieră| → depozit steril → livrare], zonă murdară presiune negativă → zonă sterilă presiune pozitivă; **autoclave dublă ușă (pass-through)** — imposibil ca materialul să se întoarcă.

**Filtre/sasuri zone sterile:** filtru personal (dezechipare→duș→echipare sterilă, 2 uși nesincrone), filtru bolnav (schimbare pat la limita sterilă), filtru material (pass), **sas cascadă presiuni** (sală + max → coridor mai mic).

## 7. Blocul operator

Zone puritate crescătoare: neutră (curat) → curată (pozitivă ușoară) → **sterilă (sală, ISO 5-7, pozitivă max.)** → murdară (negativă, evacuare).

| Parametru sală operație | Valoare |
|---|---|
| Su chirurgie generală | min. **30-36 mp** |
| Su chirurgie specială | 42-50 mp (flux laminar) |
| H liber | min. 3,00 (rec. 3,20-3,50) |
| Clasa puritate aer | **ISO 5** (laminar ultracurat mare risc) / **ISO 7** general (SR EN ISO 14644-1) |
| Schimburi aer | ≥**20/h** (rec. 25-30), HEPA **H14** (99,995%) |
| Presiune vs. coridor | **+15…+25 Pa** pozitivă |
| Temperatură / UR | 19-24°C / 45-55% |

**Anexe:** filtru personal (marche en avant, uși nesincrone), spălător chirurgical (comandă genunchi/cot/senzor, 1 post/2 chirurgi), preparare (conectat depozit steril), trezire (1,5 posturi/sală). **Finisaje sală:** pereți/tavan lavabili fără rosturi antibacterieni + **scafe rotunjite**; pardoseală **PVC omogen sudat conductiv** continuu; uși etanșe automate cu vizor; fără ferestre practicabile.

## 8. Finisaje speciale — mediu medical

Toate spațiile medicale: finisaje lavabile, dezinfectabile, netede, neabsorbante, rezistente la dezinfectanți, cu **racorduri rotunjite (scafe)** (OMS 914, OMS 961/2016).

| Zonă | Pardoseală | Pereți | Particularități |
|---|---|---|---|
| Sală operație | PVC conductiv sudat scafă | antibacterian fără rosturi | ISO 5-7, racorduri rotunjite |
| ATI | PVC sudat scafă | lavabil antibacterian | presiune controlată |
| Saloane | PVC heterogen sudat/linoleum | lavabil semilucios | scafă |
| Coridoare | PVC sudat + parapet șoc | HPL/lavabil parapet | bumper targă 90 cm |
| **Imagistică** | PVC omogen sudat | **plumb 1-3 mm echiv.** + GK, uși Pb | RMN: cușcă Faraday, fără feromagnetice |
| Laborator | rășină chimic-rezistentă | lavabil + faianță apă | rezistență reactivi |
| Bloc alimentar | gresie R11 | faianță integral | sifoane, GP 063 |
| Sterilizare | PVC sudat scafă | lavabil fără rosturi | presiune diferențiată |
| Morgă | gresie tehnică + sifon | faianță integral | temperatură scăzută |

**Protecție radiologică:** RX/CT ecranare **plumb 2-3 mm echiv.** (dimensionat de fizician medical după sarcină mA·min/săpt., distanțe, ocupare); uși plumbate + geam Pb comandă; RMN cușcă Faraday RF + interdicție feromagnetice + delimitare linia 5 Gauss.

## 10. Securitate la incendiu (arhitectură, P118-1/2013)

**Concept:** pacienți imobilizați NU coboară scări → **evacuare orizontală pe compartimente** (transfer prin uși EI în compartiment protejat adiacent, apoi ascensor pompieri).

| Măsură | Descriere |
|---|---|
| Compartimentare orizontală | ≥2 compartimente/nivel spitalizare (pereți/uși RF) |
| Uși compartimentare | **EI 60-90** autoînchidere la detecție |
| Zone de refugiu | spațiu protejat/compartiment (staționare paturi) |
| Ascensor pompieri | ≥1 (EI + alimentare rezervă) |
| Case scări | închise presurizate/desfumate EI spre exterior |
| Detecție+stingere | adresabilă totală + hidranți + sprinklere depozite/arhivă/bucătărie |
| Grad RF | **I** (R180/120, planșee REI90) |

Bloc operator + ATI = compartimente distincte cu grup+UPS + ventilație siguranță.

## 13. Concluzii

Spital/clinică multidisciplinară S+P+4E cadre b.a., **categoria B, clasa seismică I (γI 1,4), grad I RF**, PMR obligatoriu. Definitorii: (1) **separarea totală circuite** (septic/aseptic, bolnav/personal/vizitator/steril/deșeuri/lenjerie, Ord. 914) + **„marche en avant"** bloc operator + SPD; (2) **bloc operator** ISO 5-7, presiune pozitivă cascadă, HEPA H14, ≥20 vol/h, finisaje fără rosturi + scafe + PVC conductiv; (3) **imagistică** protecție plumb 2-3 mm + cușcă Faraday RMN; (4) **saloane** Ord. 914 (7 mp/pat, ≥20 mc, GS propriu, însorire ≥1,5h), orientare S/SE/E vs. bloc operator N/NE; (5) **100% PMR** (coridoare 2,20, uși 1,10-1,40, ascensor pat 1,40×2,40); (6) securitate incendiu **evacuare orizontală pe compartimente** + zone refugiu + ascensor pompieri. POT 26,1%/CUT 1,46/verzi 21,1% încadrate. Cele 7 cerințe L10/1995, verificare A/B/Cc/D/E/F. Detaliere PT+DDE cu specialiști (rezistență, HVAC steril, electrice, gaze medicale, tehnologie).
