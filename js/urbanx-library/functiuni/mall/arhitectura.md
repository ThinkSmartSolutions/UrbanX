## 1. Date generale și tema de proiectare

Memoriu de arhitectură DTAC pentru **centru comercial regional (mall) cu atrium central, S+P+2E** (galerie + atrium 3 niveluri + hipermarket + food-court + cinema multiplex + parcare).

| Element | Valoare |
|---|---|
| Teren / Ac / Ad suprateran | 42.500 / 18.900 / 47.200 (cu subsol) mp |
| GLA | ~20.000 mp |
| Categoria importanță | **B — deosebită** (HG 766/1997) |
| Clasa seismică | **II (γI,e 1,2)** — aglomerări mari |
| Grad RF | **I-II** |
| Risc incendiu | mediu (local ridicat bucătării/parcare) |

**Cadru normativ:** Legea 50/1991, 10/1995, 372/2005, HG 766/1997, HG 907/2016, Ord. MDRAP 3454/2019; P118-1/2022, P118-2/2013, P118-3/2015, **NP 068-2002** (aglomerări — CRITIC), OMS 119/2014, NP 051/2012, C107, C125/2013, NP 024-028 (parcaje), P100-1/2013.

**Capacitate (densități NP 068/P118):** vânzare unități 14.000/2,0 = 7.000 + hipermarket 4.500/2,0 = 2.250 + galerie 4.800/3,0 = 1.600 + food-court 1.200/1,5 = 800 + cinema 8×200 locuri = 1.600 → **~13.250 pers teoretic** (dimensionează evacuarea + sanitare + ventilare, nu cea probabilă).

**Temă:** PMR 100%, atrium 3 niveluri + lumină zenitală, ancore (hipermarket/cinema/food-court), confort + nZEB, separare fluxuri.

## 3. Amplasament, orientare, accese

Teren 42.500, deschidere bulevard N + colectoare V. Retrageri: aliniament 12,0 (≥6), laterală 9,0 (H/2 ≥6), **distanță siguranță foc ≥12 m** (P118), acces autospeciale 3 laturi (3,8 m, R 12). Fațada principală N/NV (umbrire); luminator zenital cu factor solar controlat; livrare S/SE (ferit).

**Accese separate (nu se intersectează):** 3 intrări publice (uși automate ≥3,0 m + sas) + hipermarket propriu + cinema propriu (E2) + 2 rampe marfă (dock, H 4,5) + deșeuri + personal + 4 rampe parcare (pantă ≤15%/12% curbe, NP 024) + **14 ieșiri urgență** la sol.

## 4. Program funcțional și zonare

Schema „dumbbell cu atrium" (ancore = tracțiune, atrium = echilibru/orientare).

| Nivel | Funcțiuni |
|---|---|
| Subsol −3,50 | parcare ~380, tehnice (CT/frig/ventilație, gospodărie+rezervă incendiu, pompe), depozite ancore, deșeuri refrigerat, post trafo/tablouri/grup |
| Parter ±0,00 | atrium (referință), galerie 0 + unități, hipermarket vânzare, GS + PMR + family room, back-of-house |
| E1 +5,00 | galerie 1 + unități (modă/servicii), balcoane atrium, GS |
| E2 +10,00 | food-court + cinema multiplex (8 săli) + entertainment + GS |

**Circulații verticale:** 8 scări rulante (treaptă 1,00, 30°, 0,50 m/s — NU cale evacuare) + 2 travelatoare (12% cărucioare) + 3 lifturi panoramice (≥1,10×1,40) + 2 lifturi marfă (2.500 kg) + **6 case scări evacuare EI presurizate**.

**GLA vs GBA:** unități mici-medii 8.500 + hipermarket 5.200 + cinema 3.100 + food-court 1.400 + servicii 1.800 = **GLA ~20.000**; + galerie/atrium 5.400 + GS 620 + circulații verticale 980 + tehnic 1.600 + back-of-house 2.200 = **GBA suprateran ~30.800**; + subsol 16.400 = Ad ~47.200. **Eficiență η = 20.000/30.800 = 65%** (optim 60-70%).

## 5. Atrium și circulația (galeria)

**Galerie = coloană vertebrală.** Unitate trecere 0,60 m, capacitate 70 pers/flux (P118). Galerie principală 8,0 m (13 fluxuri, 910 pers), secundară 5,0 (8 fluxuri), balcon atrium 4,0. Regula: lățimea liberă **NU se îngustează** pe sensul evacuării (kiosk-uri nu reduc).

**Atrium** (24×18 = 432 mp plan, H 16 m, volum 6.912 mc, luminator 380 mp, FLZ ≥2%): **desfumare CRITICĂ** — strat liber fum ≥ **2,50 m peste E2**; S_desfumare ≥ 1,5%·432 = 6,48 → **trape ≥8,0 mp** (automat) + aport aer proaspăt jos ≥ S_evacuare; alternativ **mecanic (SHEVS)** pe model plume; **cortine de fum** coborâtoare (≥1,0 m) la E1/E2 (canalizează fumul în gol, protejează galeriile). Lumină zenitală: vitraj triplu low-E g≤0,35 + protecție solară.

## 6. Unități comerciale (shop units)

Modul structural 8,10×8,10; unitate mică in-line adâncime 12-16 m, front 6-8 m, 80-150 mp; medie 150-500; junior anchor 500-1.500; H liber ≥3,50 (ancore ≥4,00). **Anatomie:** vitrină/storefront (lease line, rulou antipanică) → vânzare → back-of-shop → **ușă spre culoar serviciu**.

**Culoar tehnic de serviciu** (esențial): ≥2,40 m lățime, ≥2,50 H, aprovizionare + deșeuri + tehnic + personal fără traversarea galeriei; separare de galerie EI; lift marfă + scară serviciu.

## 7-8. Ancore

**Hipermarket** (GLA 5.200, vânzare ~4.500, H ≥4,50): acces propriu + din galerie, dock dedicat, **compartiment de incendiu propriu REI + uși EI**, program extins. **Food-court E2** (~2.600: mese 1.200 ~800 locuri + 12-16 unități): bucătării cu **hote + stingere automată (Ansul)** + separare grăsimi + canal grăsimi, igienă OMS 119 (fluxuri crud/preparat/deșeuri). **Cinema multiplex** (8 săli, ~1.600 locuri): **gradenă** (izopticã C ≥90 mm), foaier E2, cabină proiecție. **Acustică cinema (C125):** R'w ≥60-62 (pereți dubli decuplați/box-in-box), L'nw ≤50 (planșeu flotant), zgomot fond ≤30 dB(A) NC 25-30, T 0,4-0,6 s; uși acustice sas + tratament fonoabsorbant + decuplare instalații.

## 10. Securitate la incendiu (arhitectură — CRITIC)

Grad RF **I-II**. **Compartimente distincte:** mall REI 180, hipermarket (perete REI 180 + uși EI 120), cinema (REI 120-180 + EI 90-120), parcare (REI 180 + sas EI 90), tehnice REI 180, case scări REI 120-180 + presurizate; arie mărită cu **sprinklere integrale** + atrium ca volum special desfumare.

**Evacuare parter** (~3.000 pers mall): L_nec = 3.000/70·0,60 = **25,7 m**; asigurat: 3 intrări (9,0) + 4 urgență (7,2) + hipermarket (6,0) + capete (4,8) = **27,0 > 25,7** ✅. **Etaje** pe **6 case scări** (rampe 1,50-1,65, min. 2 direcții/nivel); scări rulante NU se contabilizează. **Distanțe:** un sens 15-20 m / două sensuri 30-40 m (echipat) / din unitate la galerie ≤20 m. **Uși:** sensul evacuării + **antipanică** (NP 068) + EI pe protejate + autoînchidere.

**Desfumare:** atrium (trape + cortine + aer, strat liber ≥2,50) + galerii zonat + case scări presurizate (~50 Pa) + parcare mecanică/naturală + bucătării separat. Iluminat securitate ≥1h + pictograme + marcaje fotoluminescente. **Scenariu securitate** (Ordin 130/2007) + dispecerat SSI 24/7.

## 11. Finisaje și anvelopă (C107)

Trafic foarte intens + materiale clasate A1/A2 pe căi evacuare: galerie/atrium granit/gresie PEI V R10 + placaje A2 + tavan casetat RF; food-court gresie R11 hidrofugă; cinema mochetă Bfl + acustic; GS gresie R10 + faianță; case scări beton/gresie R10 + lavabil RF. **Reacție foc căi evacuare A1/A2-s1,d0/B-s1,d0.**

**Anvelopă (C107/nZEB):** perete R' 2,10 (≥1,80, vată 15 cm); acoperiș 5,50 (≥5,00, XPS/vată 25); planșeu subsol 3,00 (≥2,90); vitraj U 1,1 (≤1,3); luminator U 1,4 g≤0,35. Verificare **condens Glaser** (barieră vapori fața caldă, fără acumulare anuală); G ≤ GN (volum compact A/V mic favorabil). Protecție solară automată luminator/S-V. Acustică tehnice fonoizolate + food-court fonoabsorbant.

## 13. Concluzii

Mall regional S+P+2E cu atrium 3 niveluri, GLA ~20.000, hipermarket+cinema+food-court + unități. Categoria B, clasa II (γI 1,2), grad I-II RF. Conform L50/1991, L10/1995, P118-1/2022+NP 068 (aglomerări — temă centrală), NP 051 (PMR 100%), OMS 119, C107, C125 (cinema). Capacitate teoretică ~13.250 pers dimensionează evacuarea (parter 27,0 > 25,7 m, 6 case scări presurizate, ≥2 direcții, REI 180, desfumare atrium strat liber ≥2,50). Fluxuri separate + culoar serviciu. PMR 100% (lifturi toate nivelurile + GS/nivel + family room + 40 PMR). nZEB (anvelopă >minim, luminator g≤0,35). POT 44,5%/CUT 0,72/GLA 20.000/η 65%/verzi 20,9%. Apt DTAC → AC; PT+DE + scenariu securitate + acustic + audit energetic. Se completează cu piese desenate + memorii specialitate + avize.
