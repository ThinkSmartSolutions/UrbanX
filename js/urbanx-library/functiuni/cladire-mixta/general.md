# MEMORIU TEHNIC GENERAL — CLĂDIRE MIXTĂ (comercial + rezidențial/birouri) — DTAC

## 1. Date generale

Memoriu general DTAC (Legea 50/1991 Anexa 1) pentru **clădire mixtă S+P+5E** — comercial/servicii parter+mezanin + locuințe colective/birouri etaje, subsol parcaj.

| Element | Valoare |
|---|---|
| Categoria importanță | **C** (element B) |
| Clasa seismică | **II (γI,e 1,2)** (III dacă comercial <400 mp/nivel; adoptat II acoperitor) |
| Grad RF | **II** |
| Risc incendiu | comercial mijlociu / rezidențial mic / parcaj mic |

**Cadru normativ:** Legea 50/1991 (+Ord. 839/2009), 10/1995, 350/2001, HG 907/2016, HG 571/2016, 766/1997, 372/2005; P100-1/2013, CR 0/2012, CR 1-1-3/1-1-4/2-1-1.1, CR 6-2013, NP 112/2014; P118-1/2/3, **NP 057-2002** (locuințe — NU NP 011), NP 051/2012, OMS 119/2014, C107, C125/2013, NP 068-02, I5/I7/I9/I13.

## 2. Tipuri de clădire mixtă

| Tip | Combinație |
|---|---|
| **A. Comercial + rezidențial** (tratat) | comerț parter+mezanin, locuințe etaje |
| B. Birouri + comercial | comerț parter, birouri etaje |
| **C. Mixt vertical podium+turn** (tratat) | podium comercial + turn suprapus |
| D. Mixt orizontal | funcțiuni alăturate |

**Tratat: Tip A/C mixt vertical cu podium comercial** — parter+mezanin comercial (podium), E1-5 apartamente/birouri, subsol parcaj comun. Impune **transfer structural** (trama comerț 7,20-8,10 vs. rezidențial 3,60-5,40, ca la hotel/podium+turn).

## 3. Necesitate și oportunitate

Densificare urbană controlată (oraș compact, SDG 11), cerere spații mixte („live-work-shop"), reactivare front comercial (vitrine → animare stradă). Oportun: utilizare eficientă teren (POT/CUT la max PUG), rentabilitate mixtă (chirii comerciale + locuințe), colmatare front fără expansiune.

## 5. Descriere generală

**Structură b.a. dual (cadre + pereți/nuclee)**, q = 5,0·αu/α1 (DCH/DCM). **PROVOCAREA transfer:** subsol/parter comerț tramă mare (7,20-8,10) vs. etaje rezidențial tramă mică (3,60-5,40) → **planșeu/grinzi de transfer** la cota +5,40 (grinzi h L/8-L/10 ~90-120 cm sau dală 60-80 cm), preiau stâlpii rezidențiali suspendați; **element critic în domeniul elastic** (fără articulații plastice).

| Element | Dimensiune |
|---|---|
| Stâlpi parter | 70×70 (nucleu) / 60×60 C30/37 |
| Pereți/nuclee | 25-30 cm C30/37 |
| Grinzi transfer | 60×110 C35/45 |
| Planșee | dală 22 (rezidențial) / 25 (comercial) C25/30 |
| Fundații | **radier general 80-100 cm** C30/37 XC2 |

Radier + cuvă etanșă (white/black box), pereți mulați/palplanșe după freatic (NP 112/120).

**Accese SEPARATE** (principiu de bază): comercial (front stradă, cotă ±0,00 fără prag NP 051) / **rezidențial (lobby propriu + recepție + control acces)** / aprovizionare (spate) / parcaj (rampă i ≤15-18%). NU se admite ca locatarii să traverseze zona comercială.

**Anvelopă:** zidărie 25 + termosistem vată 15 (λ ≤0,036) / fațadă ventilată etaje + **cortină/vitrine parter**; tâmplărie triplu U_w ≤1,3; terasă termohidroizolată + verde extensivă.

## 7. Securitate la incendiu (P118, HG 571/2016)

**Compartimentare între funcțiuni** (principiu): fiecare funcțiune = compartiment propriu.

| Separare | Element | RF |
|---|---|---|
| Comercial↔rezidențial (planșeu mezanin) | b.a. | **REI 120** |
| Comercial↔casa scării rezidențială | b.a./zidărie | REI 120-180 |
| Parcaj↔restul | planșeu+pereți | REI 120 + ușă EI 90-C |
| Între apartamente | perete | EI 60 |

**Evacuări separate:** comercial (direct exterior parter, ≥2 fluxuri/unitate); rezidențial (**2 case scări**, una presurizată); parcaj (≥2 ieșiri). NU se traversează între funcțiuni. **Instalații:** hidranți int./ext. + rezervă proprie + sprinklere (parcaj + comerț după arie, NP 127) + detecție adresabilă + desfumare (case scări/parcaj/circulații) + iluminat securitate. Grad II: stâlpi R120-180, planșee REI90-120, grinzi transfer R120.

## 9. Sistematizarea terenului

**Orizontal:** front comercial la aliniament (vitrine → activare trotuar ≥2,00 m liber NP 051); accese diferențiate (comercial front / rezidențial lateral / auto rampă / serviciu spate); platforme + 4 locuri sol + **cale pompieri ≥3,80 m**; spații verzi ≥20% (grădină spate + aliniament + terasă verde); împrejmuire transparentă ≥60%. **Vertical:** parter la cotă trotuar fără trepte (prag ≤2,5 cm NP 051), rampă subsol i ≤15% (18% cu degivrare), pluvială pante ≥1% + retenție.

## 10. Utilități și contorizare separată

Racorduri: apă (branșament + apometru + gospodărie incendiu), canal menajer (+ stație pompare subsol) + pluvial separat, electric (post trafo/trifazat), gaze (dacă e cazul + CT), termic (CT gaz/pompe căldură), telecom fibră.

**Contorizare separată (obligatoriu clădire mixtă):** electric (contor/unitate comercial + contor comun comerț | contor/apartament + comun rezidențial); apă (apometru/unitate | apometru/apartament + repartitoare); gaz/termic (contor comercial | repartitoare apartament, Legea 121/2014); **părțile comune comercial ≠ rezidențial** (asociație proprietari ≠ administrare comercial). **nZEB clasa A** (anvelopă C107 + fotovoltaic/solar terasă + pompe căldură + recuperare + LED senzori comun); CPE la recepție.

## 11. Avize și verificări

**Verificare (Legea 10/1995)** verificatori atestați MDLPA cerințele **A** (A1/Af), **B** (Cc incendiu), **C** (igienă/mediu), **D** (siguranță/accesibilitate), **E** (zgomot), **F** (energie) + instalații **Is/It/Ie/Ig/Iv**.

**Avize:** **ISU** (HG 571/2016 — comerț+parcaj+aglomerări), **DSP** (OMS 119 habitat/însorire), **APM** (mediu/deșeuri), utilități, salubritate, circulație (Poliția Rutieră), arhitect-șef, studiu geotehnic verificat Af. Documentații: CU + geotehnic (NP 074) + piese desenate + memorii specialitate + referate A-F + **scenariu securitate incendiu** avizat ISU + titlu teren.

## 12. Concluzii

Clădire mixtă S+P+5E (comercial parter+mezanin + 36 apartamente + birouri), categoria C(B), clasa II (γI 1,2), grad II RF. Urbanistic POT 58,5%≤60%, CUT 2,86≤3,00, verzi 21,4%. Structură dual b.a. cu **planșeu/grinzi de transfer** podium comercial→rezidențial (element critic elastic). **Separarea completă a funcțiunilor** (accese distincte, compartimentare REI 120, evacuări + case scări independente, **contorizare separată**) — esențială. Locuințe NP 057/OMS 119, PMR NP 051, **nZEB clasa A**, acustică C125. Verificare A-F + avize ISU/DSP/APM → apt AC. Se completează cu memoriile de specialitate + scenariu securitate + geotehnic + piese desenate.
