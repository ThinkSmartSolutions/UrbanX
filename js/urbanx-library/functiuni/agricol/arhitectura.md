# MEMORIU TEHNIC DE ARHITECTURĂ — FERMĂ AGROZOOTEHNICĂ BOVINE LAPTE (DTAC)

## 1. Date generale și temă

Memoriu arhitectură DTAC (Legea 50/1991 Anexa 1) pentru **fermă bovine de lapte, stabulație liberă cu cushete, 300 capete în lactație** + siloz + anexe. Obiecte: C1 hală adăpost, C2 sală muls + lapterie, C3 filtru sanitar-veterinar, C4 siloz orizontal + fânar, C5 depozit furaje, C6 platformă gunoi acoperită, C7 bazin dejecții, C8 rampă animale.

| Element | Valoare |
|---|---|
| Categoria importanță (HG 766/1997) | **C** (D anexe) |
| Clasa seismică (P100-1/2013) | **III (γI 1,0)** |
| Grad RF | **III-IV** |

Bunăstarea = **cerință funcțională primară** (condiționează producția + eligibilitatea APIA/PNS). **Normative:** Legea 50/1991, 10/1995, HG 766/1997, 907/2016; P100-1/2013, CR 1-1-3/1-1-4, C107/2005, P118/1999 + P118-2/3, NP 112/2014, NP 040/GP 118 (hidroizolații); **Directiva 98/58/CE** (bunăstare) + Ordin ANSVSA 75/2005 + specifice bovine, Ordin ANSVSA autorizare (biosecuritate), **OMS 119/2014** (distanțe sanitare), Cod bune practici agricole (Nitrați).

## 2. Tipuri de adăposturi. Sistemul adoptat

| Criteriu | Variante |
|---|---|
| Mobilitate bovine | stabulație **legată** (bunăstare redusă) / **liberă** (recomandat) |
| Zona odihnă (liberă) | **cushete/cubicule** (curat, confortabil) / pardoseală plină bedded pack |
| Anvelopă | închis / **semideschis** / deschis (cortină rulabilă) |
| Comparativ specii | bovine (liberă+cushete), porcine (boxe grătare, maternitate, all-in/all-out), păsări (sol ≤33-42 kg/mp sau baterii, tunel) |

**Adoptat: stabulație liberă cu cushete, hală semideschisă ventilare naturală, muls în sală dedicată (brăduleț/paralel).** Motiv: bunăstare superioară + igienă (mamite reduse) + eficiență muls + microclimat (bovine sensibile la **stresul termic de căldură**, THI).

## 3. Amplasament, orientare, distanțe

Teren extravilan agricol S 30.000 mp (3 ha), NHS sub cotă fundare. **Orientare hală:** axă longitudinală **perpendiculară pe vânt dominant** (ventilare transversală prin cortine) + streașină largă 1,00-1,50 m (protecție solară cushete vara, lumină iarna) → prioritate ventilare naturală. Ex. vânt NV-SE → axă NE-SV.

**Distanțe (OMS 119/2014 + ANSVSA):** fermă-localitate **≥500 m** (>100 capete); fermă-alte ferme (biosecuritate) **500-1.000 m**; bazin-apă suprafață ≥100 m; captare apă ≥50 m sanitară severă (HG 930/2005). **Circuite fizic separate curat/murdar** (nu se intersectează): curat (personal via filtru, furaje, lapte la limită) / murdar (dejecții, animale via rampă la limită, cadavre la ecarisaj). Împrejmuire h ≥1,80 + poartă unică + **dezinfector rutier** + filtru sanitar.

## 4. Dimensionarea adăpostului (capitolul de fond)

**Norme mp/cap (bovine lapte, cushete):**

| Zonă | Normă |
|---|---|
| Cușetă odihnă (vacă 650 kg) | **2,50×1,25 = 3,13 mp/cap** (≥1,0-1,05 cushete/cap) |
| Alee furajare | ≥3,50-4,00 m |
| Alee circulație | ≥2,50-3,00 m |
| Front furajare (iesle) | **0,65-0,75 m/cap** |
| Adăpătoare | 1/15-20 capete, min. 2/grup |
| **Suprafață utilă/cap** | **8,0-10,0 mp/cap** |
| **Volum aer/cap** | **25-30 mc/cap** |

**Capacitate: N = S_util/n_cap.** Pentru 300 capete × 10,0 = **3.000 mp util** → hală **B 30,00 × L 102,00 = 3.060 mp** (4 rânduri cushete + 3 alei circulație + 2 alei furajare). **Verificare cushete:** 102/1,25 = 80/rând × 4 = **320 cushete > 300 (raport 1,07)** ✓. **Front furajare:** 300 × 0,70 = 210 m ≤ 2×102 = 204 + capete ✓. **Volum aer:** ~9.000 mc/300 = **30 mc/cap ≥ 25** ✓.

**Zonare:** adăpostire cushete (~1.000) + alei furajare+iesle (~900) + alei circulație (~900) + **sală muls + așteptare (~250)** + lapterie (~40) + maternitate (~120, 8-10 boxe) + infirmerie/izolare (~60). H streașină ≥4,00, coamă ~8,50-9,00 + luminator.

## 5. Biosecuritate și fluxuri (CRITIC)

**Filtru sanitar-veterinar (C3) — 3 zone + duș-barieră:** (1) zonă murdară (vestiar haine stradă) → (2) **duș obligatoriu** (barieră, trecere „gol") → (3) zonă curată (echipament fermă). Niciun traseu nu ocolește dușul; separare fizică completă. + GS + spălător cizme (pediluviu) + birou + sală mese.

**Flux unic:** animale (intrare → carantină → producție → maternitate/infirmerie → rampă ieșire, fără întoarcere); furaje curat (siloz → alee furajare); **lapte curat cel mai strict** (uger → sală muls → lapterie → cisternă acces exterior, fără intrarea cisternei în producție); dejecții murdar (canale → platformă/bazin). **Rampă animale (C8) la limita incintei** — vehicul extern oprește în afara zonei curate (întrerupe vectorul de contaminare). **All-in/all-out** la maternitate/infirmerie (vid sanitar + dezinfecție); pediluvii la accese + dezinfector rutier.

## 6. Pardoseli și evacuare dejecții

Cerințe: **antiderapantă** (locomoție — bunăstare), igienizabilă, rezistentă acizi, **etanșă** (protecție sol/apă — imperativ mediu). **Alei:** beton C25/30 XA striat antiderapant + pante 1,5-2% spre canale → **racloare automate (scraper)** sau spălare hidraulică. **Cushete:** platformă înălțată + așternut (nisip/saltea cauciuc + rumeguș). **Grătare** peste canale pe trafic intens. **Hidroizolare etanșă (mediu):** beton hidrofug + membrană HDPE + rosturi hidroexpandabile — niciun purin în sol. Dejecții → solid (platformă C6) / lichid (bazin C7).

## 7. Construcții anexe

**Siloz orizontal (C4):** 3 celule tranșee pereți b.a. h 3,0. Consum siloz 25-30 kg/cap/zi × 300 ≈ 8,5 t/zi → ~3.100 t/an; densitate 700 kg/mc → ~4.450 mc; adoptat 3×(35×8×3) = 2.400 mc tampon + fânar. Sucuri siloz (levigat) în rigolă etanșă. **Platformă gunoi (C6):** placă b.a. etanșă + pante + acoperiș + ziduri sprijin 3 laturi, ~600 mp. **Bazin dejecții (C7):** b.a. impermeabilizat semiîngropat **~1.500 mc** (300 × 50 × 6 luni), dublă barieră + mixer. **Depozit furaje (C5):** ~300 mp uscat/ventilat + buncăre. **Personal (C3):** vestiare ~30 + GS/duș ~20 + birou ~18 + mese ~15 mp.

## 8. Ventilare și microclimat (arhitectural)

**Ventilare naturală** (optimă bovine): **cortine rulabile laterale** (deschise vara, parțial iarna) + **luminator coamă (ridge vent, tiraj termic)** evacuează cald/umed/NH₃/CO₂ + streașini largi. La caniculă + **ventilatoare destratificare/tunel** (stres termic THI). Controlul noxelor (NH₃ sub prag bunăstare prin ventilare + evacuare frecventă), umiditate (evită condens/boli respiratorii), temperatură (bovine tolerează frig; **riscul major = căldura**). Lumină naturală (luminator + tablă translucidă). **Microclimatul rezolvat pasiv prin geometrie** + completare mecanică la vârf vară.

## 9. Securitate la incendiu (arhitectură)

Grad **III-IV** (structură metalică protejată gr. III). Compartiment mare specific agricol; **depozit furaje/fânar (sarcină termică mare) separat** prin distanțe/pereți antifoc. **Evacuare animale:** porți largi **3,00-4,00 m** pe ambele laturi spre padocuri; aleile de bunăstare = trasee evacuare. Distanțe siguranță între obiecte; hidranți + rezervă + drum intervenție perimetral. **Anvelopă sandwich miez A2** (vată minerală) unde e cerut.

## 10. Finisaje și anvelopă

Cadre metalice deschidere mare (fără stâlpi intermediari — circulație animale) + soclu beton h 1,00-1,20 (rezistent lovire/spălare) + panouri sandwich (miez A2) + cortine rulabile + acoperiș sandwich pantă coamă + luminator. **Termoizolare C107** (confort animal, evită condens iarna/supraîncălzire vară).

| Element | Finisaj (igienizabil/dezinfectabil) |
|---|---|
| Pereți producție | sandwich față lavabilă netedă |
| Pardoseli alei | beton XA antiderapant striat + etanș |
| Sală muls/lapterie | beton epoxidic/gresie antiacidă + pante sifoane |
| Tavan/intrados | neted igienizabil |
| Filtru sanitar | faianță/rășină + gresie antiderapantă |

## 12. Concluzii (6 cerințe)

Fermă bovine lapte 300 capete, stabulație liberă cushete, categoria C, clasa III, grad III-IV RF. **A** rezistență (clasa III P100, zăpadă/vânt, NP 112); **B** foc (grad III-IV, evacuare efectiv porți largi 2 laturi, separare furaje, hidranți); **C** igienă/mediu (filtru duș-barieră, curat/murdar, finisaje lavabile, **pardoseli etanșe + bazin impermeabil**, stocare 4-6 luni Cod bune practici); **D** siguranță (pardoseli antiderapante locomoție, filtru); **E** zgomot (extravilan + distanțe OMS 119); **F** energie (C107, **microclimat pasiv ventilare naturală**). Respectă **bunăstarea** (Directiva 98/58/CE, Ordin ANSVSA 75/2005 — mp/cap, cushete, front furajare, apă, aer, lumină) + biosecuritatea ANSVSA. Se completează cu memoriile de specialitate + piese desenate. Semnat arhitect OAR.
