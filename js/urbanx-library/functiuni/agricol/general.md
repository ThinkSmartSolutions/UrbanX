# MEMORIU TEHNIC GENERAL — FERMĂ AGROZOOTEHNICĂ (DTAC)

## 1. Date generale, categorie, cadru

Piesă scrisă generală DTAC (Legea 50/1991 Anexa 1) pentru **fermă agrozootehnică**: hală adăpost animale (structură metalică deschidere mare) + **siloz cereale/furaje** + anexe (filtru sanitar-veterinar, platformă gunoi acoperită, bazin dejecții etanș, depozit furaje, cabină poartă + dezinfector roți, cântar). Fază DTAC + DTOE (Ordin 839/2009; PTh+DE ulterior HG 907/2016).

| Element | Valoare |
|---|---|
| Categoria importanță (HG 766/1997) | **C** hală/siloz, **D** anexe (B dacă peste prag IED) |
| Clasa seismică (P100-1/2013) | **III (γI 1,0)**; siloz mare valoare → poate II (1,2) |
| Grad RF (P118) | **III-IV** (risc mediu-mare din furaje/paie) |

**Cadru normativ:** Legea 50/1991, 10/1995 (6+1 cerințe), HG 907/2016, 766/1997, Ordin 839/2009, Legea 350/2001; CR 0, CR 1-1-3/1-1-4, P100-1/2013, SR EN 1990-1999, **SR EN 1991-4** (silozuri), NP 112, NP 074; P118-1/2/3; I5 (ventilare), I7/I9/I13, C107, Legea 372/2005; norme **ANSVSA** (biosecuritate + autorizare pe specii), **Directiva 98/58/CE** (bunăstare) + specifice (bovine/porcine/păsări); OUG 195/2005 mediu, **Directiva 2010/75/UE IED** (IPPC → autorizație integrată + BAT peste prag), **Directiva 91/676/CEE Nitrați** + Cod bune practici agricole, OUG 92/2021 deșeuri, OMS 119/2014 (distanțe sanitare).

## 3. Necesitate și oportunitate

Securitate alimentară + modernizare zootehnie (înlocuire adăposturi neconforme bunăstare/mediu cu BAT) + integrare pe lanț (adăpost+siloz+furaje = costuri logistice + biosecuritate). Oportun: **PNS 2023-2027 + PNRR + APIA**, investiții verzi (biogaz, economie circulară nutrienți), locuri muncă rural.

## 4. Încadrare urbanistică. Distanțe sanitare

**Amplasare frecvent extravilan:** (1) construire în extravilan pt destinație agricolă (Legea 50) cu scoatere din circuit agricol; sau (2) introducere intravilan prin PUZ. **Indicatori reduși:** POT 30-50%, CUT 0,4-1,0, verzi ≥20%.

**Distanțe sanitare (OMS 119/2014 + act. 994/2018) — CONDIȚIE de amplasament:** funcție de capacitate/specie — ferme mici 50-100 m, medii sute m, **mari/industriale până la 500-1.000 m+** față de locuințe; platforme/bazine distanțe proprii majorate; + **distanțe biosecuritate** între ferme (ANSVSA). **Necesar teren:** ~2,5-3,3× aria construită la POT 30-40% + perimetru protecție → ordinul 1-3 ha incintă + teren agricol pt dejecții.

## 5. Descriere generală. Dimensionare pe capacitate

Flux unidirecțional curat→murdar + zonare biosecuritară. Hală metalică cadre transversale, sandwich termoizolant, parter înalt, pardoseală betonată + canale dejecții.

**Capacitate: A_util = N × s_cap** (norma bunăstare mp/cap). Valori: bovine adulte 5-7, viței 1,5-3, porc îngrășat ~1,0, scroafă gestantă 2,25-2,5, broiler densitate max **33/39/42 kg/mp**. **Exemplu broiler:** N 20.000 × 2,2 kg = 44.000 kg / 39 kg/mp = **1.128 mp util → ~1.300 mp construit** (hală 18×72). *20.000 broiler < prag IED 40.000.*

**Siloz:** V = M_stoc/ρ (grâu 0,78 t/mc, porumb 0,72). Ex. 1.500 t grâu → 1.923 mc (2 celule Ø9 H15). **Anexe:** filtru sanitar (vestiar murdar-duș-curat), platformă gunoi betonată acoperită, bazin dejecții etanș, depozit furaje, cabină + dezinfector roți, cântar.

## 6. Funcțiuni, fluxuri, biosecuritate

**Curat/murdar strict separate:** curat (personal după filtru, animale sănătoase, furaj, așternut curat) / murdar (dejecții, cadavre, animale eliminate, așternut uzat). **Flux personal:** exterior → filtru (vestiar murdar → duș → vestiar curat) → producție. **Animale:** populare rampă → adăpost → livrare rampă la limită. **Furaje:** siloz → linie furajare. **Dejecții:** canale → platformă/bazin → împrăștiere.

| Zonă | Componente | Regim |
|---|---|---|
| Administrativă/acces | cabină poartă, filtru, birou | tampon curat |
| Producție | adăpost + tehnică | curat controlat |
| Furajare/stocare | siloz, depozit | curat |
| Dejecții/eliminare | platformă, bazin, rampă cadavre | murdar separat |
| Livrare | rampă animale | tranzit la limită |

## 7. Securitate la incendiu

Risc din furaje/paie/praf cereale (siloz → explozie praf ATEX). **Grad RF III-IV**, compartimentare A ≤ A_admisă, separare depozit furaje (sarcină termică mare) prin REI. **Sarcină termică:** qs = Σ(Qi·Mi)/Ac; paie/furaje 14-18 MJ/kg. **Evacuare:** personal (P118-1) + **animale (uși/porți largi spre padocuri)**; hidranți + rezervă (P118-2), detecție (P118-3), antiexplozie praf siloz.

## 9. Sistematizarea incintei

Împrejmuire + poartă unică controlată + **dezinfector roți** + filtru sanitar; **cântar-pod bascul**; drumuri tehnologice betonate (raze întoarcere autotrenuri + autospeciale); zonare curat/murdar; platforme manevră/recepție/încărcare; verzi ≥20% (tampon vizual/olfactiv/biosecuritate); bazine/platforme dejecții în zona murdară aval de surse apă.

## 10. Utilități

Apă (racord/**foraj** + gospodărie + rezervă incendiu); canal menajer separat de dejecții; **dejecții → bazin etanș + platformă acoperită** (Nitrați); electric + **grup electrogen rezervă** (ventilația nu se poate întrerupe — bunăstare); ventilare/climatizare I5 (temperatură, umiditate, NH₃, CO₂); iluminat (program lumină păsări); termic (opțional biogaz/GPL/biomasă).

## 11. Protecția mediului

**Dejecții (Nitrați + Cod bune practici):** **V_bazin = N × q_d × Z × k_s** (Z = 120-180 zile = 4-6 luni; k_s 1,1-1,3). Rate q_d: vacă lapte 40-55, porc îngrășat 4-7, scroafă 12-17, găină 0,10-0,15, broiler 0,05-0,10 l·kg/cap/zi. **Ex. 200 vaci × 50 × 180 × 1,2 = 2.160 mc.** Platformă betonată **acoperită** (fracție solidă, pantă spre must) + **bazin etanș** (lichid, fără infiltrare freatic). **Împrăștiere:** plan fertilizare, max **170 kg N/ha·an** (zone vulnerabile); S_teren = N_azot/170. Mirosuri reduse (ventilare + platformă acoperită + injectare + distanțe). **Biogaz** opțional (fermentare anaerobă → energie + digestat). **IED/IPPC** (autorizație integrată + BAT) peste prag: **păsări >40.000, porci >30 kg >2.000, scroafe >750**.

## 12. Avize și verificare. Concluzii

**Verificare (Legea 10/1995):** **A** (A1/A2 — hală/siloz/fundații), **C** (foc), **B/D** (igienă), **Is/It/Ie**. **Avize:** **sanitar-veterinar ANSVSA/DSVSA** (obligatoriu — condiție funcționare), sanitar DSP (distanțe OMS 119), **ISU** (P118), **mediu APM** (+ autorizație integrată IED dacă IPPC), **gospodărirea apelor ANAR/ABA** (captare + dejecții), electric, salubritate (cadavre SNCU) + din CU.

**6+1 cerințe:** A rezistență (CR 0/1-1-3/1-1-4, P100 clasa III, SR EN 1991-4 siloz, NP 112/074); B foc (grad III-IV, evacuare animale, hidranți, antiexplozie); C igienă/mediu (distanțe OMS, dejecții Nitrați bazin 4-6 luni + plan fertilizare 170 kg N/ha, IED/BAT, microclimat I5, biosecuritate, bunăstare); D siguranță/accesibilitate; E zgomot; F energie (C107, L372, biogaz); +7 utilizare sustenabilă resurse (dejecții fertilizant, biogaz, economie circulară). Se completează cu memoriile de specialitate + piese desenate.
